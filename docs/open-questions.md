# 未解決の論点（Open Questions）

このファイルは、仕様検討や実装の議論中に生じた**未解決の論点（未決事項）**を一元管理するスナップショット文書である。

- ADRには「下した決定」のみを記載し、未決事項はここに分離する（ADR-0019）。
- **現在未解決のものだけ**を映す。論点が意思決定されたら ADR 化し、ここからは該当行を**削除**する（解決の跡は ADR 側に残る）。
- フォーマットと運用規約は `decision-log` スキルおよび `CONTRIBUTING.md` を参照。

## フォーマット

```
- [ ] ★ <論点> — <なぜケアが必要か / 背景>（発生源: brainstorming / spec / 実装 等, YYYY-MM-DD）
```

`★` は優先対応項目のマーカー（任意。優先度が高いものだけ付ける）。
