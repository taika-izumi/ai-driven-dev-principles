## 2. 分類規則（機械的分類の手続き）

分類は次の規則をこの順で適用し、適用した規則番号を台帳の「根拠」欄に明記した。規則の外で分類した行は無い。

**規則 1 — 既存退役条項の初回行使（条項を持つ 46 行）**。ADR-0100 決定 2 に従い、条項の条件の成否を比・構造的基準より先に判定する。

- **1-A**: 条項の対象範囲に集計期間内の検出実績・同型 delta が実在する → 条項の条件は**不成立（退役不可が確定）**→ keep とし、退役候補にしない。
- **1-B**: 当該行の検出実績が 0。ただし条項が共通して用いる「長期にわたり」の定義は現時点で未確定である（ADR-0100 決定 5 が Issue-0048 の未解決論点として明記）ため、条件が**成立するとは判定できない**。したがって条項は分類の根拠にならず、規則 2 / 3 の結果に従う。
- **1-C**: 条項が当該行個別の条件を持たず母体検査へ相乗りする（ADR-0099 が E-02 について明記）→ 個別の成否を判定できないため規則 3 の既定へ。

**規則 2 — 比判定トラック（80 行）**

- **2-0（最優先）**: 検査型で検出力**未実証** → 比を使わず保留（観測継続）。再判定条件に検出力の実証を含める。本号は**規則 1-A の keep にも優先する**（ADR-0100 決定 2 が検出力未実証の行を保留へ倒すことを明示的に命じるため）。該当は C-09 の 1 行で、同行は規則 1-A の条件（条項の対象範囲に検出実績が実在）を満たすが保留とした。
- **2-1**: 検査型で検出力実証済み → keep。実証済み 9 行はいずれも比 > 0 であり、比の値から退役側へ振れる行は無い（比の数値的な切り分け閾値は Phase A で事前登録していないため、後決めの閾値を導入しない）。
- **2-2**: 予防・閾値型 → 逸脱率が高いほど機能していない側、低いほど keep 側という事前登録に従う。比の低さを退役材料にしない。本トラックの最大値は 0.03 のため全行 keep 側。
- **2-3**: 記録・証跡型 → 欠落検出 0 かつ 1 回あたりコストが高い場合に簡素化。**高コストの判定基準**は「1 回あたりコスト」欄が全体の読解・全数走査・全件突合・5 手順以上の走行・複数ファイルの作成のいずれかを明示していること。それ以外は keep。検出 0 件だけでは退役側へ振らない。

- **3-1**: (c) で受容のみ案の見送り理由が崩れている場合に退役候補 → **該当 0 行**（詳細は 3-3）。
- **3-2**: (a) の重複が具体的な重複先とともに示せ、かつ当該行の機能が他行に完全被覆され、当該行の発火実績が 0 の場合に退役候補 → **該当 0 行**。(a) の具体性は必要条件であって十分条件ではない（ADR-0100 決定 2 の「〜に限る」）。完全被覆の成否は台帳の (a) 欄の記述ではなく**重複先の正本**（対象成果物・観点・発火点）で確認する（3-3 の I-18 の解説）。
- **3-3**: それ以外 → 保留（観測継続）。
- (b)(d) 単独では退役候補にしない（ADR-0100 決定 2）。
