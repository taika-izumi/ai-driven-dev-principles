# Audits

一回限りの監査（棚卸し調査）の記録の索引。各監査はディレクトリ単位で追跡型の記録（確定後不変）として保管する。配置根拠は `docs/overview/folder-structure.md` の運用規約（種別サブフォルダはオンデマンド作成・列挙されていない新種別）による。『方法の決定』は監査手法を定めた ADR を、『結果の決定』は Phase B のユーザー判断を記録する別 ADR（ADR-0100 決定 4 参照）を指す。『結果の決定』欄は Phase B 終了時に一度だけ追記して行を完成させるものであり、それ以外の索引更新は行わない（ADR-0100 の「以後更新されない」と整合させるための規定）。
