# ADR-0036: 選択UI誤操作対策は環境側の誤操作防止設定とテキスト提示フォールバック規範の両輪とする

- **Status**: Accepted
- **Date**: 2026-07-05

## Context

Issue-0005: 構造化質問ツールの選択UI（Claude Code の AskUserQuestion 等）はワンクリックで回答が即確定し、確認の一拍がない。誤クリックが「方針確定」として扱われ、意思決定の継続検出ルール（ADR-0006）により即座に ADR 作業へ増幅される。2026-07-05 の Issue-0012 対策サイクルの brainstorming 中に実例が発生し（判断2件が誤クリックで意図せず確定、取り消し・再ヒアリングとなった）、当初は「後戻りコストの高い重要判断では選択UIをやめ、選択肢＋推奨をテキスト提示する規範への改定（ADR-0024 の改定）」が対策方針として合意されていた。

本サイクルの調査で、Claude Code v2.1.195 以降には環境変数 `CLAUDE_CODE_DISABLE_MOUSE_CLICKS=1` があり、TUI 全体のマウスクリック確定を無効化（キーボード操作のみに限定）できることが判明した（出典: Claude Code 公式ドキュメント Fullscreen rendering 節。関連する既知の GitHub issue: anthropics/claude-code #71547, #72614）。これにより誤クリックの根本原因を環境側で構造的に塞げる。一方、本ガイドラインはツール非依存・他プロジェクトへの配布前提であり、GitHub Copilot CLI や環境変数未設定の環境では防止策が効かないため、環境設定だけでは規範としてカバーしきれない。

## Considered Alternatives

- **案1（採用）: 環境設定＋環境ベース2分岐のフォールバック規範。** 誤操作防止の環境設定（Claude Code では `CLAUDE_CODE_DISABLE_MOUSE_CLICKS=1`）を推奨環境設定として文書化し、規範は「防止策が環境で確認できれば質問の重要度を問わず選択UIを使ってよい／確認できなければ質問の重要度を問わずテキストの番号選択肢で提示する」の2分岐とする。判定がエージェントの機械的な観測（設定値の確認）だけで完結し、防止済み環境では選択UIの利便性を全面維持できる。
- **案2: 環境設定のみ。** 環境変数の文書化だけで Issue-0005 を close する。最小工数だが、Copilot CLI・未設定環境では課題が残存したまま close になり、配布前提のガイドラインとして不完全。不採用。
- **案3: 規範改定のみ（当初方針）。** 環境に依存しない一方、Claude Code では環境設定で根本解決できるのに選択UIの利便性（ワンクリック回答）を一律に捨てることになる。不採用。
- **案4: 防止策のない環境でも「重要判断」に限りテキスト化する（当初合意の方向性）。** 「後戻りコストの高い重要判断」の定義（ADR 起票トリガー連動等）が別途必要になり、規範が複雑化する。環境ベース2分岐の方が判定が単純・観測可能で、防止されていない環境では軽微な質問でも誤クリックの巻き戻しコスト（言い直し）は小さくないため、一律テキストで足りる。不採用。

## Decision

案1を採用する。

1. 誤操作防止の環境設定を推奨環境設定として文書化する。Claude Code では `CLAUDE_CODE_DISABLE_MOUSE_CLICKS=1`（settings.json の `env`、または OS の環境変数。v2.1.195 以降）。
2. `CLAUDE.md`「ユーザーへの質問と意思決定要求」節の「構造化された質問ツールが利用できる場合はそれを使う」（ADR-0024）を、次の2分岐に改定する（ADR-0024 自体は Superseded にせず、本 ADR がツール選択条項の上書きを定義する）:
   - クリック誤確定の防止策が環境で確認できる場合（Claude Code では環境変数 `CLAUDE_CODE_DISABLE_MOUSE_CLICKS=1` の設定を確認できた場合）: 質問の重要度を問わず構造化質問ツールを使用してよい
   - 確認できない場合（同等の防止設定が知られていないツールを含む）: 質問の重要度を問わず、テキストの番号付き選択肢（選択肢＋推奨）で提示する

## Consequences

- 良い影響: 誤クリック→即確定→ADR 増幅という Issue-0005 の因果経路が、環境設定のある環境では構造的に消える。防止策のない環境でも重要判断はテキスト提示で保護される。
- 良い影響: 軽微な確認では選択UIの利便性を維持できる（全面テキスト化を回避）。
- 留意点: 環境変数は Claude Code 固有であり、他ツール（Copilot CLI 等）の同等設定は現時点で未調査。フォールバック規範がその穴を塞ぐ。
- 留意点: `CLAUDE.md` を変更するため `scripts/sync-template.ps1` によるテンプレート同期が必要。
- 事実: 本リポジトリのユーザー環境（Claude Code 2.1.201）には 2026-07-05 に `~/.claude/settings.json` の `env` として適用済み（次回セッションから有効）。
- **部分修正（ADR-0085、2026-08-13）**: 分岐 1（防止設定を確認できた場合は使用してよい）は、事象確認済みモデル（ADR-0085 のリスト参照）で動作している場合には適用されない（ADR-0085 が優先し、構造化質問ツールを使用しない）。分岐 2 と環境設定の文書化は現役のため Status は Accepted のまま維持する。
