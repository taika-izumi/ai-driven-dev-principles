# ADR-0072: 確定前レビューの発動はユーザーの指示に限り、AI は次手として提示するにとどめる

- **Status**: Accepted
- **Date**: 2026-08-05

## Context

ADR-0067 は、非コード成果物（計画・仕様）の確定前レビューを新規スキルとして立てることを決めたが、発動条件は authoring 時の設計事項として残した。

> **発動条件（どの規模から必須にするか）は本 ADR では決めていない。** 3 観点の独立レビュー＋実証の実行はコストが大きく、閾値の設計を誤ると小規模な作業まで重くなる。

コストと便益はどちらも実測がある。

- **コスト**: 独立レビュー 3 観点 ＝ サブエージェント 3 体。さらに「計画中のコードをスクラッチで実行する」実証が加わる
- **便益**: `LoopForAlpha-2026-07-19-05` では独立レビューが Critical 5 件を検出し、直前の自己レビューはその全数を取り逃していた。`LoopForAlpha-2026-07-28-11` では計画中のテストコード 10 件すべてが `CommandNotFoundException` で 1 件も動かないことを検出した

## Considered Alternatives

1. **不可逆性と規模で自動判定する**（実装を伴う計画・仕様で、影響ファイル 3 件以上または新規モジュール作成なら必須） — ファイル数は数えられる事実であり ADR-0032 の実行可能性を満たす。`feature-block-design` の「中規模以上」判定とも基準が揃う。ただし閾値の妥当性を裏づける実測がない。3 件という数字は既存スキルからの借用であって、本課題の根拠エントリから導かれたものではない
2. **規模を問わず常に必須** — 取りこぼしが原理的に無い。一方で 1 ファイルの規約追加にもサブエージェント 3 体分のコストがかかる。重すぎる規範は守られずに形骸化する
3. **ユーザーの指示に限る** — 採用

## Decision

**確定前レビューは、ユーザーが実施を指示したときにのみ発動する。** 規模・不可逆性による自動必須化は行わない。

ただし **AI 側からの提示は省略しない。** ADR-0067 が定めた `start-work` Phase 2 マッピング表への配線により、`writing-plans` および `feature-block-design` の完了後の次手として毎回提示される。発動の判断はユーザーに残るが、**判断の機会を作る責務は AI 側にある。**

この形は ADR-0032 の実行可能性規範に沿う。「どの規模から必須か」はエージェントが妥当に判定できる根拠を持たないため、判断主体をユーザーへ明示的に移す。

## Consequences

- **コストがユーザーの制御下に入る。** サブエージェント 3 体＋実証の実行は、ユーザーが便益を認めた場面でのみ発生する
- **形骸化を避けられる。** 守れない必須規範を置くより、確実に提示される任意工程のほうが実際に実行される見込みが高い
- **取りこぼしうる。** ユーザーが提示を見送った計画は、自己レビューだけで確定する。Issue-0034 が示した自己レビューの限界（載せる項目の選定漏れと既存コードとの相互作用を 1 件も検出できていない）は、その計画に対しては残る
- **Issue-0034 の `corrections` 型は完全には解消しない。** 根拠 7 件のうち人間の介入は 5 件で、全クラスタ最高の比率だった。次手提示により「レビューは行われたか」と人間が思い出して差し込む起点は AI 側へ移るが、実施の判断そのものは人間に残る
- **自動必須化は将来の選択肢として残る。** 本スキルの実行実績が貯まり、ユーザーが閾値化を指示した時点で、代替案 1 を実測に基づいて設計し直せる
- **部分修正（ADR-0080）**: Decision 本文の提示点「`writing-plans` および `feature-block-design` の完了後」は、ADR-0080 により spec 確定点（3 通り）と plan 確定点の 2 種へ一般化され、あわせて提示内の推奨順位の規則が加わった。骨格（発動はユーザー指示のみ・AI は毎回提示する・自動必須化しない）は現役のため、Status は Accepted のまま維持する
- **部分修正（ADR-0105）**: pre-finalization-review 固有の「自動必須化はしない」条項は start-work 提示規則へ吸収された（発動ゲートの意味は不変）
