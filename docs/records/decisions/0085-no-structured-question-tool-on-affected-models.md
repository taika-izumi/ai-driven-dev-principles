# ADR-0085: 事象確認済みモデルでは構造化質問ツールを使用せず、テキストの番号付き選択肢に一本化する

- **Status**: Accepted
- **Date**: 2026-08-13

## Context

ADR-0029 は「構造化質問ツールと同一ターンのテキストが表示されない」事象への対処として、事象確認済みモデル（Claude Fable 5）に限り「質問の自己完結」＋「長い説明が必要な場合のテキストフォールバック」の 2 本立てを定めた。

しかしその後も事象の再発が続き（2026-08-03 にモデル切替後の再発、2026-08-13 にも発生）、2026-08-13 にユーザーから「モデルが Fable 5 の時は質問ツールを使用しないでください。メッセージ本文が表示されず、質問ツールの質問と選択肢しか見えない現象がこれまで何度も確認されています」と明示指示があった。自己完結形式であっても、質問文・選択肢説明の欄に収まる情報量には限界があり、表示されない本文に文脈を置く事故が構造的に再発する（自己完結の判定そのものがエージェントの裁量判断であり、確実に守られる保証がない）。

## Considered Alternatives

1. **事象確認済みモデルでは構造化質問ツールを全面不使用とし、テキストの番号付き選択肢に一本化する（採用）** — 事故経路（本文に文脈を置く／自己完結判定の誤り）を構造的に塞ぐ。ADR-0029 が不採用とした案 C（常時テキスト回帰)と異なり、モデル条件付きのため未確認モデルでは構造化ツールの利点を維持する
2. **ADR-0029 の 2 本立てを維持し、自己完結判定を厳格化する** — 判定基準をどれだけ厳格化しても判定主体はエージェントのままで、誤判定の再発経路が残る。実測で複数回再発しており不採用
3. **無条件の全面不使用（モデル条件なし）** — 事象が発生しないモデルでの利便性（誤操作防止・回答コスト減。ADR-0024/0036）を不必要に失う。ADR-0029 の案 A' と同型の過剰対応で不採用

## Decision

案 1 を採用する。`CLAUDE.md`「ユーザーへの質問と意思決定要求」のモデル条件付き対処を次の内容に置き換える。

1. **適用条件**（ADR-0029 から継承）: 「構造化質問ツールと同一ターンに書いた説明テキストがユーザーに表示されない」事象が確認されているモデルで動作している場合にのみ適用する。事象確認済みモデル: Claude Fable 5（2026-06〜2026-08 に複数回確認）。新たなモデルで確認した場合はリストへ追記する
2. **対処内容**（本 ADR で変更）: 事象確認済みモデルでは、質問の重要度・自己完結の可否を問わず**構造化質問ツールを使用しない**。すべての質問を、説明と番号付き選択肢（推奨を先頭に「（推奨）」付き。ADR-0024 の提示規範）を含むテキストのみのターンで行う
3. **撤去基準**（ADR-0029 から継承）: 事象が発生しないモデルの利用が常態化したとユーザーが判断し撤去を指示した時点で本項目を削除し、本 ADR を Deprecated に更新する

ADR-0029 は Superseded by ADR-0085 とする（適用条件・撤去基準の枠組みは本 ADR が継承し、対処内容を置換）。実装位置は ADR-0029 と同じく Layer 2（`CLAUDE.md`）のみとする。

## Consequences

- 事象確認済みモデルでの「本文が見えないまま選択を迫られる」事故が、エージェントの裁量判定を経由せず構造的に防止される
- 事象確認済みモデルでは構造化ツールの誤操作防止効果（ADR-0036 の環境設定と併用していた）を失い、番号の打ち間違い等はユーザーの入力注意に依存する
- 構造化質問ツールのタイムアウト停止規範（ADR-0035）は、事象確認済みモデルでは発動機会がなくなる（規範自体は未確認モデル向けに現役のまま）
- `CLAUDE.md` は template.manifest 対象のため、変更後に `scripts/sync-template.ps1` の実行が必要

## 過剰適合点検（ADR-0079）

| 観点 | 判定 | 根拠 |
|------|------|------|
| 出所の偏り | 問題なし | 出所は 1 プロジェクト環境・1 モデル世代（Claude Fable 5、Claude Code の AskUserQuestion、2026-06〜2026-08 に複数回実測＋2026-08-13 のユーザー明示指示）。単一出所だが、無条件規範ではなく事象確認済みモデル列挙によるゲート付き規範であり、是正パターン「観測可能な発動条件でゲート」を適用済み |
| システム種別依存性 | 問題なし | 対話 UI の表示特性への対処であり、開発対象システムの種別・技術スタックに依存しない |
| AI モデル/ツール依存性 | 問題なし | モデル依存の事象そのものを扱う規範。確認済みモデルの列挙で適用範囲を限定し、未確認モデル・将来モデルには適用されないため、将来モデルの性能発揮を制限しない |
| 退役経路 | 定義済み | ユーザーが撤去を指示した時点で CLAUDE.md から削除し本 ADR を Deprecated 化（判断主体をユーザーへ明示的に移譲。ADR-0029 の撤去基準を継承） |
