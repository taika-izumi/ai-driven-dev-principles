# ADR-0126: 作業継続の挙動は同一開始点から条件を一つずつ変えて比較する

- **Status**: Proposed
- **Date**: 2026-09-06

## Context

Issue-0126の調査中、AIはbrainstormingの調査経路を選び、結果報告後にstart-workの次手案内へ戻らなかった。後続の前提確認にも説明だけを返した。Claude Codeのローカル導入記録はsuperpowers 5.1.0、今回のCodexで読んだ本文は6.3.0であり、後者には調査報告で終える経路がある。版差は確認できるが、原因の確定には至っていない。

## Considered Alternatives

- スマホまたはモデル固有の問題と見なし、直ちにガイドラインを変更する。原因が未分離で、不要な規範を増やすおそれがある。
- Claude CodeとCodexをそのまま比較する。環境全体の差は観測できるが、モデル・ハーネス・スキル版の影響が混在する。
- 同一開始点と会話を基準に、一条件ずつ変えて比較する。試行負担はあるが、原因候補を分離しやすい。

## Decision

2026-09-06のユーザー指示に基づき、検証方針を保存し、本セッション開始時のコミット `153d47c5ef46dca45001550a952c309605414503` から検証用ブランチ `codex/verify-start-work-baseline` を作成する。

検証は、次手案内・途中質問後の作業継続・判断待ちの明確さ・未承認作業への過剰な進行を区別する。同一条件の反復、スキル版、モデル、PCとスマホの操作経路の順で、比較可能な一条件ずつ変える。具体的な再現用の入力と観測項目は `docs/records/minutes/2026-09-06-workflow-continuation-validation.md` に記録する。

本記録は今回限りの調査方針であり、配布する規範やスキルの変更ではない。ブランチ作成と方針保存は承認済み。比較試行そのものは未実施のため、本ADRは検証準備段階のProposedとして記録する。

## Consequences

開始コミットと再現用の会話を再利用できる。Git外のプラグイン・モデル設定・未追跡資料・会話履歴は別途統制する必要がある。今回の会話を知るセッションで試すと事前知識の影響があるため、各試行は新しいセッションから始める。

既存ADRの置換はない。対策の採用、スキルの改定、試行回数の固定は本決定に含めない。
