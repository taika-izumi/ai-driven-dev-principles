# ADR-0127: Codexの選択肢提示の競合は症状に応じた設定手順で案内する

- **Status**: Accepted
- **Date**: 2026-09-06

## Context

Issue-0127では、Codexのモード指示とガイドラインの選択肢提示の競合が見つかった。CLIの生成入力で除外設定の効果を実測し、ユーザーはCLIで意図した挙動、アプリrun5で選択肢表示を報告した。作業継続の改善は十分に確認していない。ユーザーは既に報告した情報だけで各種文書へ記録するよう指示した。

## Considered Alternatives

- AGENTS.mdの質問ルールをCodex向けに変更する。上位指示との競合は残り得るうえ、他のハーネスにも影響する。
- Codexの全利用者に設定変更を必須化する。未確認の環境へ一般化し、モード指示全体の除外を強制するため採らない。
- 症状がある環境向けの対処として記録する。既存規範を維持し、確認済みの範囲と戻し方を利用者へ示せる。

## Decision

READMEのCodex導入節から、`docs/reference/codex-collaboration-mode-question-format.md`へ案内する。手順は一時指定・ユーザー設定・確認・復元と影響範囲を扱い、全員の必須設定にはしない。AGENTS.md・スキル本文は変更しない。

報告済みの試行結果は既存の検証記録へ追記し、再収集しない。Issue-0127で選択肢表示への対処と文書化を追跡する。作業継続の一般的な解決は含めない。

## Consequences

配布規範を増やさず対処へ到達できる。将来の版では設定の要否が変わるため、確認版・情報源・見直し条件を手順に残す。追加の監視・検査工程・台帳は設けない。既存ADRの置換はない。
