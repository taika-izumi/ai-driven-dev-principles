# ADR-0128: 人間の関与を独立した費用項目から外す案を検討する

- **Status**: Accepted
- **Date**: 2026-09-06

## Context

Issue-0126の対応表では、人間の関与を独立した費用項目として残す候補を示した。ユーザーは、人間の操作負担を理由に機能を見送る判断までAIが担うのは過剰であり、AI駆動開発では膨大な手作業を前提とする場面も多くないと指摘した。

## Considered Alternatives

- 独立した費用項目から外す案を検討する。不要な確認や手戻りの削減は、AIの仕事の進め方として扱う。
- 開発中の人間の作業負担に限定して独立項目を残す案を検討する。利用時の操作量や機能採否への適用を除外する説明が必要になる。

## Decision

ユーザーは2026-09-06に前者を選択した。Issue-0126では、人間の関与を独立した費用項目から外す案を検討する。不要な確認・説明のやり直し・手動転記などの削減は、AIの作業の進め方として整理する。

今回の選択は調査の進め方であり、配布する規範の採用確定ではない。既存ADR-0124・0125の規範は変更しない。

## Consequences

- 検討方針は確定し、その後の具体的な規範への反映はADR-0130として2026-09-07に実装・検証した。

- 人間の関与量を理由にAIが機能の見送りを決める方向へ、目的関数を広げることを避けられる。
- 独立項目を外しても、人間に必要な作業を隠したり、その負担をゼロと扱ったりする根拠にはならない。
- 残る比較軸や具体的な適用の検討材料はIssue-0126で管理する。
