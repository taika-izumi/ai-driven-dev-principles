# ADR-0135: 振り返り時点の変更は費用対効果の裏付けが不足するため今回は見送る

- **Status**: Accepted
- **Date**: 2026-09-07

## Context

Issue-0131では、マージ後に作る振り返り記録を実装と同じ変更単位へまとめる案を比較した。起票元 `docs/records/retrospectives/flow/2026-09-07-wording-dispatch.md` では、追加の記録確定が必要になったことを観測しているが、記録漏れや不具合の発生は確認していない。

AIは当初、マージ前に本体を記録し、後から必要分を補う方式を推奨した。ユーザーが変更の手間・デメリットに対する利益を問い直し、AIは維持負担の評価が不足していたと訂正した。ユーザーは本会話で「今回は見送る（現行方式を維持し、Issueには費用対効果による保留理由を残す）」という選択肢1に「1で」と回答し、見送りを承認した。

## Considered Alternatives

- マージ前にすべて記録する: 実装と一緒に確認・取り込みができるが、統合時の課題は別の記録経路で拾う必要がある。
- 前に本体、後に必要分を補足する: 統合時の課題も拾えるが、記録済み範囲、追記の条件、マージ失敗やPR待ち、引き継ぎ終了処理との整合を設計・維持する負担がある。終了記録の追加コミットが必ずなくなるわけではない。
- 今回は見送る: 現行の追加記録の負担は残るが、変更と将来の保守に投資せず、必要性を再検討できる。

## Decision

Issue-0131への対処は今回は見送り、openのまま保留する。現行のマージ後に振り返る方式を維持する。実装と記録をまとめる利点に対して、関連手順の改定・検証・将来の保守負担を上回る効果の裏付けが現時点では不足しているためである。恒久的な不採用や課題のクローズとはしない。

## Consequences

- スキル・規範・仕様・配布物は変更しない。ADR-0010の現行決定は置換しない。
- 記録漏れ、PR承認経路の支障、追加の記録確定の負担など具体的な材料が得られた場合は、Issue-0131へ追記し、再着手はユーザーの判断に委ねる。
- 本ADRは見送り判断の記録であり、新しい一般規範や実施設計を定めるものではない。
