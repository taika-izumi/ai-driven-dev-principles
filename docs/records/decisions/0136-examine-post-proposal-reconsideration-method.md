# ADR-0136: 次の作業として初期案提示後の問い直しの検証方法を検討する

- **Status**: Accepted
- **Date**: 2026-09-08

## Context

Issue-0125の振り返りから、レビュー投資の見直し（Issue-0114）と、初期案提示後に懸念・将来費用を問い直す効果の検証（Issue-0132）が着手候補となった。2026-09-08の会話で「1. Issue-0132の検証方法を検討する／2. Issue-0114の残論点を整理し、対処対象を選ぶ」という提示に対し、ユーザーが「1で」と回答した。この対象選択はユーザーの個別承認による。

## Considered Alternatives

- Issue-0132の検証方法を検討する: 問いが具体的で、比較条件と評価方法を絞りやすい。
- Issue-0114の残論点を整理する: 既存の実測を活用できるが、レビュー深度・検査範囲・予算などから対象を選ぶ必要がある。

## Decision

次の対象をIssue-0132とし、初期案提示後の問い直しの効果を確かめる検証方法を検討する。対象選択の承認を、実験条件の採用・実験実行・規範変更への包括的な許可として扱わない。

## Consequences

具体的な比較方法と判断基準を検討できる。一方、現時点の観測は1サイクルで対照条件がなく、効果の結論には追加の検証を要する。検討事項の正本は `docs/working/issues/flow/0132-post-proposal-design-reconsideration-effect.md` とする。Issue-0114の優先度を恒久的に下げる決定ではない。
