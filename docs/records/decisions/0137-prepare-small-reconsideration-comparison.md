# ADR-0137: 問い直しの検証は事前指示なしを含む2題材・5条件で具体化する

- **Status**: Accepted
- **Date**: 2026-09-08

## Context

Issue-0132への着手をADR-0136に記録した。2026-09-08の会話で、3条件（事前指示のみ・一般的な再検討・懸念と将来費用の具体的な問い直し）を2題材で比較する提案を示した。「1. この小規模比較を具体化する（推奨）—題材・入力文・評価基準・実行方法まで私が整えます。実験実行と規範への採用は相談事項とします／2. 最初から原因の切り分けを重視する」という選択肢に、ユーザーが「1で行きましょう」と回答した。この個別承認を判断の分担の基準とする。

- 2026-09-08の追加承認: ユーザーが事前指示なしの検証の必要性を指摘した。「1. 両方を追加して5条件にする／2. 指示なしの初期案だけ追加して4条件にする／3. 現行3条件を維持する」の提示に、「ですよね。事前指示なしで後から問い直しも重要だと思います。1で行きましょう。」と回答。事前指示なしの初期案と、そこからの具体的な問い直しの追加を承認した。元の分担のうち実験実行・規範採用の相談は維持する。

## Considered Alternatives

- 2題材・5条件: 事前指示だけ、後の問い直しだけ、両方の比較が可能。設計回答は10回となる。
- 2題材・4条件: 指示なしの初期案だけ追加し、事前指示の有無を比べる。指示なしからの問い直しの効果を扱えない。
- 2題材・3条件の小規模比較: 追加検証に進む価値を低い試行回数で検討できるが、反復による再現性や原因の詳細は扱えない。
- 別コンテキストでの点検と反復も含めて比較: 原因の切り分けを進められる一方、実行・評価の費用が増える。

## Decision

2026-09-08の確定承認: ユーザーが「あなたから見て、今回の変更差分回りに問題は見られませんか？もし見られないようであれば、このまま確定して進めましょう。今回はあくまでも小規模検証なので、ここは時間を書けないことを優先したいです」と指示。主担当が修正差分と比較条件を照合し、進行を阻む設計上の問題なしと判断した。計画9節の採否で追加レビューを省略して確定し、計画内の動作確認・実験へ進む承認として扱う。規範採用や条件拡張はこの承認に含めない。

2題材・5条件の小規模比較を具体化する。条件は「事前指示なし・初期案」「事前指示なし・具体的な問い直し」「事前指示あり・初期案」「事前指示あり・一般的な再検討」「事前指示あり・具体的な問い直し」。題材ごとに事前指示あり／なしの初期案を1つずつ生成し、追送は対応する初期案の履歴から分岐させる。評価は根拠のある改善、要件保持、誤指摘・不要な追加、実行と確認の費用を扱い、追加検証に進む価値を判断する材料とする。

判断の分担は、この検証方法の具体化が完了するまで有効とする。題材・入力文・評価基準・実行方法の具体化と、その整合確認はAIに任せる。実験実行、規範への採用、題材数・比較条件の拡張は事前相談とする。細部の変更で承認済みの比較構造を変えない。

## Consequences

ユーザーに入力文の作成や毎回の問いの手入力を求めず、実行判断に必要な一式を用意できる。2題材の結果だけで一般的な優劣や再現性を結論づけない。具体案は `docs/working/plans/2026-09-08-issue-0132-reconsideration-pilot.md` を参照し、実行の承認とは区別する。
