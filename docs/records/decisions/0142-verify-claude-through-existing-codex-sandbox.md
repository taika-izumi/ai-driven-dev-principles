# ADR-0142: 既存CodexのあるWindows環境でClaudeの限定実行経路を検証する

- **Status**: Accepted
- **Date**: 2026-09-08

## Context

Issue-0136の共通改定とCodexのローカル操作の保護試験は済んだが、Claudeの実行あり検査とCodexの副担当経路が未確認である。ユーザーは説明を受けた後、「では検証を進める必要がありますね。先ほどの質問は1でお願いします」と回答し、既存Codex併用の限定経路の検証を選択した。

## Considered Alternatives

- 既存Codexを併用する限定経路: 現在のWindows環境と確認済みのOS制限を利用できる。Claudeからの接続と直接操作の除外を別に検証する必要がある。
- WSL側を準備する: Claude・不足依存の導入と認証確認、Windows用検証との互換性確認が必要になる。
- 保留する: 追加作業を抑えられるが、両ツールの対応確認が未完のまま残る。

## Decision

既存CodexがあるWindows環境に限定し、Claudeの実行操作をCodexの保護されたコマンド実行へ接続する方式を優先検証する。Claudeの直接編集・汎用シェル・無関係な外部操作を除外した実効構成で、正常な検査、保護代用品への拒否、子プロセスへの継承、既存記録の保全、結果回収を確かめる。

これは検証対象の選択であり、Claude利用者全員へのCodex必須化、新たな常設起動基盤の導入、保護条件の緩和、公開・利用環境への導入を承認したものではない。試験用の接続補助はこの実証に限定する。ADR-0141の共通条件とツール別確認の方針は維持する。

## Consequences

追加インストールを避けて実証できる可能性がある一方、接続部分の引数・利用可能ツール・出力先を確認する作業が増える。成功時も確認したOS・版・依存が既存である条件を明示し、CodexなしのClaude環境へ一般化しない。方式の実証結果と未完部分はIssue-0136の実装検証ノートへ記録する。
