# ADR-0153: 検証担当Codex本体も隔離する構成の再検討へ進む

- **Status**: Proposed
- **Date**: 2026-09-09

## Context

ADR-0152のホスト上の子Codexを専用MCP接続に制限する構成について、v2計画タスク0では全実効ツールを起動前に取得する経路を特定できなかった。読み取り調査は`docs/records/experiments/2026-09-09-linux-pilot-activation.md`。取得方法の不在を断定したものではないが、現仕様の開始条件を満たさず後続を停止した。

「子Codex本体も隔離する構成を再検討する（推奨）」と「現構成の追加調査を続ける」を提示し、ユーザーは本会話で「1で」と回答した。この個別承認を再検討への移行の根拠とする。

## Considered Alternatives

1. 現構成の実装ソース・診断経路を追加調査する。既存設計を保てる可能性があるが、全実効ツールの取得経路が見つかる保証はない。
2. 子Codex本体も隔離する構成を再検討する。ホストの全機能の除去への依存を減らす方向で、認証・モデル通信・停止を設計し直す。

## Decision

案2の設計検討へ進む。既存v2実装計画の後続実装は保留する。主担当2種、検証担当Codex、ファイルとGit履歴の独立コピー、追加テスト作成と再検証、日常の本文転記不要という要求を維持する。

## Consequences

- この決定は検討方向の選択であり、具体的な隔離方式や認証・通信方式の採用ではない。ADR-0152をこの時点で別の確定設計へ置換しない。
- モデル起動、コンテナ起動、イメージ準備、認証情報の移送、外部送信、導入・公開の承認を含まない。
- コピー・履歴・回収の既存資産を参照し、利用者に必要となる初回設定と継続運用の負担を具体案に含める。
