# ADR-0154: 独自の隔離基盤を作り込む前に既存基盤を比較する

- **Status**: Proposed
- **Date**: 2026-09-09

## Context

ADR-0153の構成再検討中、ユーザーは先駆者の実運用構成を質問した。公開一次資料を照合した結果、隔離した開発環境、Git・テスト・PR、制御処理と実行環境の分離を利用する事例が確認できた。

「認証方式を決めて独自構成を作り込む前に、既存基盤で今回の保護条件をどこまで満たせるかを比較する」という提案へ、ユーザーが「ありがとうございます。ではその方針で進めましょう」と回答した。本会話のこの回答を比較着手の承認とする。

## Considered Alternatives

1. 独自の認証・通信・実行分離設計を続ける。要求に合わせられるが、基盤の実装・実証・保守を自ら負担する。
2. 既存基盤との適合と不足を先に比較する。既製の隔離・認証機能を活用できる可能性があり、自作範囲を判断できる。

## Decision

案2へ進む。検証担当Codex、主担当Claude CodeとCodex、資料とGit履歴の独立コピー、原本保全、追加テスト作成と再検証、通常の本文転記不要を比較条件とする。隔離・認証・通信制限・証拠回収・Windows環境の準備負担を確認する。

## Consequences

- ADR-0153の再検討を進める方法を具体化する。特定基盤の採用、クラウド利用、保護条件の緩和は決定していない。
- 旧v2計画の後続実装と認証方式の個別選択は保留し、比較結果を判断材料にする。
- 導入・更新・ログイン・イメージ準備・モデル起動・対象リポジトリの外部送信は別途具体化する。
