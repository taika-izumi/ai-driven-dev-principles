# ADR-0161: 合成題材の試作中はクリップボード文字列書込を例外として受容する

- **Status**: Accepted
- **Date**: 2026-09-10

## Context

sbxのホストclipboard文字列書込について遮断方法を確認できなかった。主担当はコピー内容の上書きと貼り付け事故を防ぐ条件であり、原本ファイル保護とは別と説明した。試作中・直後は貼り付けを避け、使用前に信頼できる元からコピーし直す負担も提示した。ユーザーは試作限定の意味を確認し「OKです。では推奨案で進めましょう」と回答。これを本例外への個別承認とする。

## Considered Alternatives

1. 書込禁止を維持して、拒否機構や別の実行境界を検討する。
2. 小さな合成題材の試作中だけ文字列書込経路を明示した例外とし、その他の保護を維持する。

## Decision

案2を採用する。clipboard文字列書込の拒否を試作の起動条件から外すが、書込を回収の経路として使わない。画像読取は無効を維持する。試験開始時と結果に書込の可能性を明記し、ホストへの作用が一切ないとは表示しない。利用者は試作中・直後にコピー済み内容をそのまま貼り付けず、使う前に信頼できる元からコピーし直す。

## Consequences

- clipboardの内容保全と貼り付け安全を隔離基盤だけでは保証しない。これは同等の代替保護ではなく、明示した例外受容。
- 自動のclipboard読取・退避・復元・消去はしない。試作成功だけで通常運用へ自動拡張しない。
- 原本・基準Git・control・認証の保全、共有なし、通信なし再実行、SSH転送拒否は維持する。
- 本決定は実モデル起動、認証、実プロジェクト送信、ホスト設定の変更の承認を含めない。
