# ADR-0163: ロードマップでは確認工程の費用と判断の適用不全への対処を先行する

- **Status**: Proposed
- **Date**: 2026-09-10

## Context

ユーザーがClaude Code Insightsの2026-09-10レポートの評価を依頼し、その評価を踏まえて必要ならロードマップを更新するよう指示した。対象レポートは利用者環境の`C:/Users/d12an/.claude/usage-data/report-2026-09-10-003550.html`。本文や他プロジェクトの会話は転載せず、既存Issueと照合した判断だけを残す。

Issue-0140は確認工程の費用が主作業を上回る実測、Issue-0124は既存の費用比較が採否で使われない再発を持つ。直前の会話でも、既存範囲内の読み取り調査に再び継続確認を求めた。ロードマップ旧案の0136→0138→0124では、他の作業にも積み上がる確認負担への対処が後になる。

## Considered Alternatives

1. 旧順序を維持する。隔離の対処に集中できるが、確認負担の改善がその完了待ちになる。
2. 確認工程の費用と判断の適用不全を先行し、隔離は既存成果と保護条件を保存する。別の設計へ無断で置き換えず、再開時は成立を左右する能力試験から進める。
3. レポートの並列レビュー・毎回の全件検証・自動復旧を追加する。新しい常設工程と環境依存が増え、費用低減の根拠も不足する。

## Decision

案2をロードマップへ反映する。ユーザーの「必要なら更新」という個別委任は、直前の評価に基づく優先順位・調査事項の改訂に適用する。Issue-0140→0124を直近の整備候補とし、不要な再確認はまずADR-0133と既存分担規定の適用確認で扱う。規範同士の重なりが原因の場合にIssue-0142へ接続する。

Issue-0136は中断を維持する。再開後、採用可否を左右する能力確認を詳細実装より先に行う。Issue-0138は実証前の先行課題として維持し、現に完了基準を妨げる場合には優先する。費用改善のために隔離・権限・証拠・停止の条件を緩和しない。

環境事前確認、複雑なシェル入力の扱い、主張の証拠、変更契約の確認、指示の重複整理は後続の調査候補とする。新たな必須スキル・Hook・固定人数・採用率・回数上限は今回導入しない。

## Consequences

- **部分修正（ADR-0166）**: 2026-09-10、Issue-0140・0124の対策完了後は別のIssueや組織設計へ直行せず、モデルに進め方を任せる条件との比較を先に準備する。0136の中断、操作承認と保全、既存の費用比較方針は維持し、0138は選んだ比較・実証を現に阻害する場合に先行する。本ADRはProposedのままとする。

- 本決定はロードマップの順序と判断材料の改訂であり、個別Issueの実装、隔離検証再開、ツール導入、設定変更、公開の承認ではない。
- ADR-0140は未確定の段階案として維持し、先行順序を本決定に合わせて更新する。他の段階・配布境界は維持する。
- 効果は既存の報告・レビュー・worklogから、必要な品質と承認を保ちながら不要な再確認・反復・維持物が減ったかを確認する。測定専用の台帳は設けず、情報不足は未評価とする。
- 既存worktreeのADR-0149〜0162との採番衝突を避け0163とした。中断中worktreeの仕様・履歴をこの変更へ取り込まない。
