# ADR-0164: 利用条件を変えない実測結果の追記を初回フルレビューの強い推奨から除外する

- **Status**: Proposed
- **Date**: 2026-09-10

## Context

Issue-0140の調査で、規範文書への実測追記と利用条件の変更を一括して扱う曖昧さを確認した。`cf46d94` は拒否リストの利用を許容する変更を含み、単なる事実追記ではない。`d0a83ef` の同規範ファイル差分は既存条件を維持した観測の追記だった。比較範囲と費用の限界は `docs/working/issues/flow/0140-confirmation-cost-outgrows-work-in-small-norm-updates.md` を参照。

ユーザーは2026-09-10、本タスクで「限定改定案の設計へ進む（推奨）」を「1で」と選択した。承認対象は、利用条件を変えない事実追記を初回フルレビューの強い推奨から外し、必要な検証とレビュー選択肢を維持する設計方針である。

## Considered Alternatives

1. 既存の推奨判定に限定的な但し書きを加える。意味の判定は必要だが、既存の通常型・方式判断を使え、新しい管理物を要しない。
2. 規範を変えず既存の委任・方式選択だけで対応する。変更負担はないが、事実追記の初回フル推奨について分類の曖昧さが残る。
3. 小改訂をまとめて確認する。回数低減の可能性はあるが、実測結果を逐次判断する作業を遅らせる。利用条件の変更を一律に待たせる単位は設けない。

## Decision

案1を採り、`skills/pre-finalization-review/SKILL.md` の初回推奨判定に、要求・許可・禁止・適用範囲・手順・保護の成立判断を変えない実測結果の追記を対象に数えない条件を設ける。根拠の訂正が従来の判断を崩す場合は除外しない。

確定点での提示、レビューの選択肢、有効な委任、必要な検証を維持する。新しい成果物の型・台帳・スクリプトは設けず、除外後の推奨順位は既存の通常の判断へ委ねる。レビュー不要を一律に推奨する変更ではない。

ADR-0080の初回推奨条件の部分修正に当たる。提示点など残りの決定は維持する。ADR-0120の型分類は既存の推奨判定への参照に従い、型の追加はしない。

## Consequences

- 実測追記という文書の形式だけで初回フル推奨を立てる曖昧さを減らす。確定点の回数自体は減らさない。
- 意味の取り違えによる過小評価は残る。小規模・過去の指摘ゼロ・費用比を除外条件にはせず、条件変更を含む対照例で文案を点検する。
- 詳細文案・承認済みの判断の分担・検証例はIssue-0140へ置く。2026-09-10、レビュー後の「このまま設計を確定」へのユーザー回答「1で」で設計を確定した。実装・検証後までProposedを維持する。過去のレビューの正当性や費用低減効果を事後的に確定するものではない。
