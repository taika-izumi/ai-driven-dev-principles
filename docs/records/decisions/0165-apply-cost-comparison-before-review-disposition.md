# ADR-0165: レビュー指摘の費用比較は既存の採否手順と対応表に組み込み、自動検査は最終手段とする

- **Status**: Accepted
- **Date**: 2026-09-10

## Context

Issue-0124は、ADR-0125で導入した費用比較が配布先に届いていても適用されなかったとして再開された。2026-09-08の申し送りでは、前提の実在確認で判断が止まり、新設・増設の費用比較を行わず指摘27件を採用したと報告されている。根拠は同Issueの検討状況とそこから参照する配布先の一次記録であり、本サイクルでは配布先の実行を再現したものではない。

2026-09-10、本会話で提示した「既存手順と対応表への組み込み」と「自動検査も含めた設計」に対し、ユーザーは「それは最終手段にしたいですね。1で」と回答した。自動検査とはエージェントの出力をスクリプト等で検査する仕組みを指すと確認したうえで、前者を選択した。これは本Issueの方針への個別承認であり、後続のレビュー実施や公開への包括委任ではない。

## Considered Alternatives

- 既存の採否手順と対応表へ費用比較を組み込む。判断する場所で比較結果を確認でき、別の検査器を維持する必要がない。記載・読み取りの負担と、エージェントによる適用漏れの可能性は残る。
- 出力の必須項目をスクリプト等で検査する。記入漏れの検出には使えるが、出力書式・検査器・実行経路の維持が必要であり、記入されていても比較内容の妥当性は保証できない。今回の対策としては採らず、最終手段とする。
- 現行の段落をそのまま維持する。追加負担はないが、既存の比較が使われなかった再発への対処にならない。

## Decision

確定前レビューの既存採否手順を、指摘ごとに「必要な修正と根拠、対応案、増設する場合の代替・維持費用、採否」の順に判断し、結果を既存の対応表・報告に短く残す形で具体化する。文言の変更でも新しい義務を加える対応は増設として扱う。

費用比較の基準はADR-0125を維持する。要求と実測または再現可能な失敗経路、簡素な代替、導入・運用・保守・副作用、今回限りか継続維持かを比較する。全件採用だけで失敗とせず、必要な修正と目的を超える改善、追加物が生んだ問題を区別して判断する。

今回、自動検査器・独立した審査工程・専用台帳は作らない。自動検査の採用は最終手段として改めて判断する。本決定はADR-0125の比較基準を置き換えず、その適用手順を具体化する。

既存の対応表・報告には、次の内容を判断順に含める。横長の表を必須にせず、指摘ごとの短い箇条書きでもよい。費用の詳細は新設・増設を採用候補に含む場合に記載し、全指摘へ一律に費用欄を埋めさせない。

| 判断順 | 記載内容 |
|---|---|
| 前提と根拠 | 満たす要求・守る対象と実体の確認箇所。必要な修正か、目的を超える改善か、今回足したものが生んだ問題かを理由に含める |
| 対応案 | どこをどう直すか。新設・増設を含むかを明示する。文言だけの変更でも義務が増える場合は含める |
| 増設案の比較 | 防ぐ失敗の実測または再現経路、文言修正・簡素化・受容で足りるか、導入・運用・保守・副作用、維持期間を短く示す |
| 採否と理由 | 先の確認と比較を根拠に採否を決める。増設案で比較が抜けていれば、その案の採用判断前に補う |

対象は `skills/pre-finalization-review/references/review-procedure.md` の手順5と、対応する現用仕様書 `docs/current/specs/2026-08-05-dispatch-and-pre-review-skills-design.md`。変更理由と導入後評価の参照は既存の `examples-and-evidence.md` へ接続する。前提確認・費用比較の説明をこの順序へ整理し、同じ規範を別工程へ複写しない。

検証では、既存記録の小さな文言訂正、必要な増設、不要な増設、追加物の簡素化の例に当てはめ、必要な修正を費用だけで排除せず、増設の比較漏れを採否前に識別できるか確認する。書式の検査器は作らず、配布生成と既存の検証を行う。判断例での確認と、実際の利用で適用漏れが減った実績は区別する。

## Consequences

採否の前に費用比較を確認する位置が明確になる。短い記載を既存の対応表・報告に含めるため、判断結果を読み返せる。一方、手順と書式だけでは適用を強制できず、比較の有効性は後続の利用事例で確認する必要がある。自動検査器の開発・保守負担は生じない。

## 評価可能性

導入後3サイクルの既存の対応表・報告から復元できる増設案を数え、採否前に比較した内容と、比較漏れへの利用者介入を確認する。1件以上の増設案を見込むが、機会・記録が足りなければ効果は未評価とする。全件採用という結果だけで不適切と判定しない。
