# ADR-0167: モデル裁量との初期比較は既存のCodex・Claude Codeの契約枠を使う

- **Status**: Accepted
- **Date**: 2026-09-10

## Context

ADR-0166に基づく比較実行案の具体化で、利用方式により実行方法と費用の測り方が変わるため、既存契約枠・API従量課金・ツール別の利用方式を提示した。ユーザーは2026-09-10、本会話の選択肢「既存のCodex・Claude Codeの契約枠で進める」に「1で」と回答した。同じ内容の許可は取り直さず、比較設計の確定チェックポイントで本記録を確定する。

## Considered Alternatives

1. 既存のCodex・Claude Codeの契約枠を使う。新規契約やAPI課金の準備を増やさず、普段利用する環境に近い条件で比較できる。一実行当たりの請求額を直接比較できるとは限らない。
2. API従量課金を使う。請求額を比較しやすいが、別の認証・課金枠の準備が必要になる。
3. ツールごとに利用方式を変える。個別環境に合わせられるが、費用指標と運用条件が揃いにくい。

## Decision

初期比較は選択肢1とする。費用評価では、取得できる利用量と所要時間を用い、契約枠の消費とAPI料金換算・実請求額を区別する。API従量課金への切り替えや利用枠の追加購入を本承認に含めない。

## Consequences

- 既存利用環境に近い比較となり、新しい課金方式の準備を避けられる。
- 契約枠は他の通常作業と共有され得るため、全体の残量変化をこの比較だけの消費と断定しない。取得できない費用情報は不明として扱う。
- 本決定は利用方式のみを対象とする。題材・実行条件の設計や実験起動の承認を代替しない。ADR-0166の比較方針を具体化するもので、同ADRは置換しない。
