# ADR-0169: 比較準備の残作業は必要性と進捗を条件に次セッションで継続する

- **Status**: Accepted
- **Date**: 2026-09-10

## Context

準備・採点60分の枠を約59.9分使用した時点で比較本体は未着手だった。ユーザーへ残作業と計数範囲を説明した後、ユーザーは「本当に必要な作業であり、『作業がループに陥る』、『過剰な検証を重ねて全く進捗が生まれていない』などでなければ。次のセッションで続きを実施していただいて構いません」と指示した。

本会話のこの発言を、提示済みの比較準備の残作業に対する条件付き継続許可として記録する。30分追加、90分・330分への変更という数値案への同意とは扱わない。

## Considered Alternatives

1. 残準備が比較の開始・評価に必要で、新しい事実や成果物を得られる場合に続行する。ユーザーの指示に沿い、既存の成果を再利用できる。
2. 60分の到達だけを理由に数値延長の承認を取り直す。今回の条件付き継続許可を反映できない。

## Decision

案1を採用する。次セッションは完了済みTask 2・3を繰り返さず、Task 1の残件から進む。各確認がどの未確認事項を解消し、比較開始や評価へどうつながるかを確認する。同じ試行で新しい証拠が増えない、検証だけが増えて比較へ近づかない場合は止め、原因と進め方を相談する。確認済みの事実は、新たな変更・失敗・懸念がない限り再検証しない。

準備・採点60分を、今回許可された残作業を止める唯一の理由にはしない。経過時間は保持し、リセットや無制限の作業許可への読み替えはしない。新たな固定時間枠は設定しない。

## Consequences

- ADR-0168の準備時間による停止の扱いだけを部分修正する。比較本体の各30分・計240分、モデル・題材・品質条件、通常環境の保全、追加課金なし、比較起動前の確認と操作承認は維持する。
- 新しい仕組みの追加や比較範囲の拡大まで任されたとは扱わない。進捗の確認には既存の計画・実行記録を使い、専用の監視や記録基盤は増設しない。
- 本セッションでは引き継ぎだけを更新し、実作業は再開しない。
