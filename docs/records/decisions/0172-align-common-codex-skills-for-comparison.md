# ADR-0172: Codex比較の共通補助スキルを起動設定で明示する

- **Status**: Accepted
- **Date**: 2026-09-10

## Context

事前確認の公式developerメッセージでは、モデル裁量の親は5スキル、子は7スキル、既存手順の親子は34スキルだった。意図した2プラグインの27スキルに加え、deep-research-workとplugin-managementの2スキルの有無が親の条件間で異なっていた。

両補助プラグインを両条件で明示的に有効にした非モデル入力表示では、共通7件が一致し、差は意図した27件だけになった。証拠はcontrol/launch-packet/common-skill-catalog-check.json。子の既存の公式入力は既に共通7件を持つ。

ADR-0168に記録した起動手順の詳細化の委任に基づくAI判断として、条件差を揃える設定調整を採用する。モデル・題材・合格条件・上限・通常設定の変更は含めない。

## Considered Alternatives

1. 両補助プラグインを両条件で有効と明示する。既に観測した子の共通入力に親を揃え、非モデル診断で同一性を確認できる。
2. 両補助プラグインを親子とも無効にする経路を追加調査する。入力は減らせる可能性があるが、子の実測も追加で必要になる。

## Decision

案1を採用する。Codexの両条件で `plugins.deep-research-work@openai-curated-remote.enabled=true` と `plugins.plugin-management@openai-curated-remote.enabled=true` をプロセス限定で指定する。ガイドラインとsuperpowersは既存手順条件だけ有効にする。起動時の入力一覧に別の差があれば比較不能として停止する。

## Consequences

- 共通の補助スキルの利用を指示するものではなく、比較の入力差を揃えるための指定である。インストールや通常設定変更は行わない。
- 実行済みの修正前事前確認は保全し、本比較の結果には用いない。修正後の親の入力は非モデル診断で確認し、子は既存の公式入力と照合する。
- 比較起動時にも一覧を確認する。全般的なツール・モデル評価へ結果を一般化しない。
