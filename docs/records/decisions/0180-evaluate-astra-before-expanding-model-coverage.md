# ADR-0180: 初期比較はAstraとSolで実施しClaudeの環境整備を保留する

- **Status**: Accepted
- **Date**: 2026-09-11

## Context

ADR-0168では2モデル・2題材を選び、モデルごとに現行手順が必要な品質・継続性へ及ぼす効果と負担を調べる方針だった。Claudeの環境整備が長引き、最新保存時点で準備時間の下限約3時間48分、モデル診断17回、本比較0回となった。

2026-09-11にユーザーは「方針転換しましょう。OpenAIのモデルで検証を行いましょう」と指示した。AIはAstraだけの4実行へ縮小したが、ユーザーは同じ会話で「最高性能のものと、solあたり」「モデル性能が変わった時に、ガイドラインでどこまで手順を提示するべきか」と目的を訂正した。これは提供元の限定であり、性能の異なるモデルを比較する目的を外す指示ではなかった。未コミットの本ドラフトを訂正し、個別指示の根拠を保持する。

## Considered Alternatives

1. AstraとSolで比較する。同じCodex環境と固定入力・検査を再利用し、モデルによる手順の便益と負担の違いを調べられる。
2. Astraだけで比較する。実行数は減るが、今回維持すべきモデルによる違いの問いには答えられないため採用しない。
3. Claudeの環境整備を続ける。提供元の広さは保てるが、初期評価の開始を遅らせるため今回は保留する。

## Decision

初期比較はAstraとSolの2モデル・2題材・2条件とする。指定は `gpt-6-astra / medium` と `gpt-5.6-sol / medium`。同じモデル内の2条件で推論設定・入力・環境・権限を揃える。日時処理のAstra対比較を先に行い、成立後にSolの日時対比較、両モデルの対象セッション指定へ進む。各30分、8実行の作成側合計240分とし、子と再開は同じ実行へ合算する。

Claudeの追加診断と今回比較のためのsbx整備は保留する。既存の入力・固定検査・Codex環境の成功証拠は再利用する。Solのモデル指定・読み込み等のモデル依存部分は当該起動時に確認し、Astraの観測をSolの実測へ読み替えない。既存の保護・認証・追加課金禁止とADR-0169の準備継続条件は維持する。

## Consequences

- **部分修正（ADR-0181）**: Solの本比較の推論設定はlowへ変更。その他の決定と過去の準備実績は維持する。
- ADR-0166・0168の代表モデル選定を部分修正する。2モデル・8実行と、モデルごとに必要な支援の違いを調べる目的は維持する。
- まずモデルごとにガイドラインあり／モデル裁量の差を評価し、その差をモデル間で比較する。2モデルの素点差だけをガイドラインの効果にしない。
- 性能順位を実測前に固定せず、結論は使用したモデル・設定・実行基盤・題材へ限定する。今回の非効率さからモデル判断と現行指示の因果を断定しない。
- 保護縮小・通常設定変更・外部公開・別モデルへの無断置換は含めない。過去資料と費用を保持し、比較不能時に新規環境整備を自動追加しない。
- 2026-09-11、ユーザーが準備完了までの実施を指示。準備と整合確認を完了し本決定を確定した。本比較は0回で、次の実行指示を待つ。実証と5観点の照合は `docs/records/experiments/2026-09-11-openai-comparison-preparation-complete.md` を参照。
