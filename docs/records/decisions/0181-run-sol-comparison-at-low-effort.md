# ADR-0181: Solの本比較は推論設定lowで実行する

- **Status**: Accepted
- **Date**: 2026-09-11

## Context

ADR-0180の比較実行中、Astraの日時・モデル裁量条件が終了し、日時・既存手順条件が進行している時点で、ユーザーは「Solの検証はeffort lowで実施してください」と明示指示した。Solの本比較は未起動であり、この個別指示を変更の承認根拠とする。

## Considered Alternatives

- Solをlowに変更する: 最新のユーザー指示に対応する。過去のmedium準備結果と本比較のlowを区別する必要がある。
- Solをmediumのまま実施する: 旧計画には一致するが、最新の指示に反するため採用しない。

## Decision

Solの4実行・6起動段階はすべて `gpt-5.6-sol / low` とする。公式の子を使う場合もlowを指定する。Astraは `gpt-6-astra / medium` を維持する。Solの起動引数・依頼本文・ハッシュ・実モデルと推論設定の照合値を一致させる。

## Consequences

- ADR-0180のSol推論設定だけを部分修正する。モデル・題材・条件・実行順・各30分／全体240分・保護・課金制約は維持する。
- 各モデル内の2条件で推論設定を揃える。モデル間の比較はAstra/mediumとSol/lowの組み合わせの差であり、モデル単体の差とは解釈しない。
- Sol/mediumの過去の起動・保護確認記録を改変しない。lowの実行実績としては扱わず、本比較の公式記録で実際の推論設定を照合する。不一致なら後続を止める。
