# ADR-0182: 第一段階から未知IDをエラーとして扱う

- **Status**: Accepted
- **Date**: 2026-09-11

## Context

小機能の第一段階でAstraが未知IDの扱いを質問し、機能未実装で停止した。第二段階では終了コード2・既存CSV不変を既に定めていたが、第一段階には明記がなかった。ユーザーは「第一段階からエラー終了、終了コード2、CSVは変更しない」という選択肢1に「1で」と回答した。この個別承認に従う。

## Considered Alternatives

- 第一段階から終了コード2・CSV不変に揃える。第二段階と整合し、ユーザーが選択した。
- 第一段階は既知IDだけを対象にし、未知IDの扱いを第二段階まで留保する。今回は選択されなかった。

## Decision

小機能の全条件で、第一段階から未知IDを含む指定は終了コード2とし、CSVを作成・上書きしない。同じ追記を未起動の第一段階依頼へ反映し、停止済み第一段階には回答として渡す。第二段階の要件と最終固定検査は維持する。

## Consequences

- 8実行の構成、Astra/medium・Sol/low、保護と時間上限は維持する。
- 既存の第一段階停止記録は保存し、同じ会話・run_idの追加起動段階で継続する。相談前127.848秒も同一30分枠へ合算し、回答待ちは稼働時間から分ける。
- 第一段階の入力変更と人の仕様判断1件を記録する。停止済み条件は途中回答、他条件は初期依頼への追記となるため、会話履歴・起動回数の差を隠さず比較上の限界として示す。
