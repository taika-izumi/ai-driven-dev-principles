# ADR-0183: 初期比較を終了し追加評価は段階3の具体的な採否前に限定する

- **Status**: Accepted
- **Date**: 2026-09-11

## Context

初期比較8実行・14起動段階は機能検査に合格した。継続情報はAstraの両条件とSol/lowの既存手順で復元でき、Sol/lowの裁量条件では前回の検証成功結果が保存されていなかった。既存手順では仕様内の設計への再確認も観測した。各条件1回で途中の入力・確認履歴に差があり、長期保守・拡張やADRによる将来費用低減は測定していない。準備の長期化も、ガイドライン・AIの判断・環境それぞれの因果を分離できていない。

ユーザーは、満足できる品質、保守・拡張を続けるための将来費用低減、成果につながらない時間・トークン消費の回避を評価の目的として再確認した。その上で「API利用上限の都合もあるので、今回の検証はこれで終わり」と指示し、結果によるロードマップの変更と次の評価の価値・時期を検討して更新することを委任した。本決定はこの文書更新の委任に基づくAI判断であり、新たなモデル実行・現行規範の改定・公開の承認ではない。

## Considered Alternatives

1. 初期比較を終了し、段階3で具体的な改善案を絞った後、その採否・適用範囲を変え得る限定評価を行う。既存成果を使い、未評価の将来費用を無視せず、直ちに利用枠を消費しない。
2. すぐに長期保守・方針転換まで含む追加の一式比較を始める。評価範囲は広がるが、終了指示に反し、候補が曖昧なまま準備費用を再び積み上げる。
3. 短期の機能合格と時間差だけで手順を削減し、今後の評価を行わない。負担は減るが、記録欠落と将来費用の未測定を無視する。

## Decision

案1を採用する。段階2の初期比較は完了とし、追加試行・モデルによる追加レビュー・Claudeやsbxの再整備は今回行わない。利用枠の回復だけで自動再開しない。

段階3は、既存の検証記録・スキル・課題から改善案を具体化するところから始める。追加モデル実行なしで検討できる、成果に照らした準備の継続判断と既委任事項の再確認を先に照合し、必要な記録の保存と工程の軽量化を具体化する。独自の役割分担や開発ループの詳細化は必要性が判明した場合に進める。

追加評価には条件付きの価値がある。何を採用・縮小・維持する判断か、既存証拠で何が不足するか、結果で判断がどう変わるかを先に定め、段階3の当該変更の採否・限定試用前に最小の確認を置く。長期保守・設計判断の追跡は、関連する実際の追加変更の機会に観測し、重要記録の撤去判断より前に確認する。適用モデル・基盤の拡張は段階4で扱う。具体的な起動・上限は実施時に合意する。

## Consequences

- ADR-0166の比較先行を実施済みの状態へ進め、以後の追加評価の時期を具体化する。他モデルへの一般化禁止、品質・権限・継続性の下限、記録の保全は維持する。
- 「詳細手順の追加便益を観測しなかった」と「現行手順・ADRが不要」を区別する。必要な意思決定理由・検証証拠・未完了事項を削減する決定ではない。
- 見込みの薄い方針の継続は、今後の成果と残る費用を代替・縮小・保留と比較する改善候補とする。準備時間の全量を無駄と断定せず、具体的な継続判断の改善は後続設計で扱う。
- 次の評価を終えるまで通常の開発や無関係な改善を一律に止めない。専用基盤・常設監視・新たなモデル別ガイドライン一式を先に作らない。
- 本更新の確定前の独立レビューは、利用枠の制約と検証終了の指示により見送る。主担当の文書整合確認を独立レビューとして記録しない。

## 過剰適合点検（ADR-0079）

| 観点 | 判定・根拠 |
|---|---|
| 出所の偏り | 比較題材の出所は1プロジェクト、2モデル設定（Astra/medium・Sol/low）、各条件1回。準備の記録とユーザーの終了指示も参照する。汎用的な優劣やADR不要へ一般化しない |
| システム種別依存性 | 小規模CLI改修の結果はその範囲へ限定。後日の保守・設計理由の調査を未評価として保持し、段階3の該当機会で確認する。ADR-0166の品質・継続性の条件を引き継ぐ |
| モデル・ツール依存性 | 今回の構成だけを確認済みとし、適用拡大は段階4。現在の利用上限を全利用者向けの恒久的な制限にしない。既存の保護と操作承認を維持する |
| 見直し条件 | ユーザーが次の改善・評価を選ぶ時点で、採否を変える問いがなければ追加評価を見送る。評価工程が判断を変えず負担だけを増やす記録が得られた場合、この位置づけの縮小・撤回を提案しユーザーが判断する |

本決定はロードマップ限定の順序変更で、汎用スキル・常設の評価制度は新設しない。次に段階3の候補を選んだ機会に、既存のADR・実行記録から、評価で採否が変わったか、準備が目的化しなかったかを確認する。観測機会がなければ未評価のまま残し、専用台帳や一律の反復は追加しない。
