# ADR-0204: 隔離検証の今後の方針は、AI組織の必要性の検討を先に行い、その結論まで保留する

- **Status**: Accepted
- **Date**: 2026-09-20

## Context

隔離検証の共通起動処理（v3、合成題材に限った試作）は2026-09-18にmasterへ統合した（f8bce07）。次サイクルの主題として、今後の方針を (i) レビュー用へ広げる、(ii) 開発用にも広げる、(iii) 試作で止める、の3案から決めることを利用者と合意していた（`docs/working/handoff/master.md`、2026-09-19）。

2026-09-20、方針を決める前提として「実プロジェクトで検証担当に自分でテストを書かせて実行させたい場面が近いうちにあるか」をAIが確認した。利用者の回答は次のとおり。隔離環境が要るのは、AI組織（役割を分けた複数のAIエージェントで自律的に開発を進める体制）を組み、実装担当が書き換えてはいけないファイルを書き換える事態を防ぐ場合である。ただし、AI組織を組めていない現状でも開発はそれなりに回っており、AI組織が本当に必要か、どのプロジェクトで導入するかは、まだ何も考えていない。

現状のレビューと用意済み検査の書き込み防止は、標準サブエージェントのツール制限（ADR-0143・0144）で成立している。今の試作で子が返せるのはテストと既存.pyの置換だけで、AI組織の実装担当を隔離する形（(ii) に当たる）までは追加設計が要る。

ユーザーの個別承認: AIが提示した3案に対し、利用者は「一度『AI組織が本当に必要か』を検討しましょう。2で。」と回答した（2026-09-20）。

## Considered Alternatives

1. **試作で止め、再開条件を記録する**（AIの推奨）: 追加投資をやめ、「AI組織の導入を検討し、対象と隔離の要件が具体化したら再検討する」と残す。費用は最小だが、AI組織の要否を検討しないまま止める判断を先に確定することになる。
2. **AI組織の必要性の検討を先に行い、隔離検証の方針はその結論まで保留する**（採用）: 広げる動機の有無を先に確かめる。検討の費用がかかり、その間は試作の残存物（停止中のVM・全体保存のOAuth・通信規則）の保留が続く。
3. **今広げる（(i) または (ii)）**: 要求が決まる前に推測で作ることになり、手戻りの可能性が高い。独立試験1回が約1時間40分かかる（Issue-0156）ほか、Issue-0152〜0155の対応が先に要る。

## Decision

隔離検証の今後の方針（広げる／止める）は決めず、「AI組織が本当に必要か」の検討を次の主題として先に行う。隔離検証の方針は、その検討の結論が出た後に改めて決める。

理由は、隔離検証を広げる動機がAI組織による自律開発にあり、その必要性と導入先が未検討のままでは、広げる判断も止める判断も根拠を欠くためである。

検討の結論が出るまで、隔離検証への追加投資（Issue-0152〜0156の対応、適用範囲の拡大）は行わない。

## Consequences

- 次の主題は「AI組織が本当に必要か」の検討になる。検討の進め方・範囲は本決定に含まず、検討の開始時に決める。
- Issue-0152〜0156は保留のまま残る。Issue-0157（停止中のVM・全体保存のOAuth・通信規則の後片付け）の扱いは本決定に含めず、別に利用者へ確認する。
- 隔離検証の実装・仕様・ADR・実験記録はmasterに残り、結論に応じて再開または後片付けへ進める。
- 本決定はAI組織の導入、実環境の構築、VMや認証情報の削除、公開の承認を含まない。
- 検討が長引くと、試作の残存物の保留も長引く。保留を続けるかどうかは、利用者が判断し指示した時点で見直す。
