# ADR-0206: 隔離検証は試作で止め、追加投資をしない

- **Status**: Accepted
- **Date**: 2026-09-20

## Context

隔離検証の共通起動処理（v3、合成題材に限った試作）は2026-09-18にmasterへ統合した（f8bce07）。今後の方針は、(i) レビュー用へ広げる、(ii) 開発用にも広げる、(iii) 試作で止める、の3案から決めることになっていたが、広げる動機がAI組織による自律開発にあるため、ADR-0204でAI組織の必要性の検討の結論まで保留した。

その検討の結論として、ADR-0205はAI組織を今は導入せず、先に不在中の判断要請を減らすと決めた。AI組織の再検討条件の一つは「書き換えてはいけないファイルを既存の手段（ツール制限・gitの差分確認）で守れないと分かったとき」であり、これに当たるかどうかは、不在中の判断要請を減らす取り組みを運用した後でなければ分からない。

現状のレビューと用意済み検査の書き込み防止は、標準サブエージェントのツール制限（ADR-0143・0144）で成立している。試作の制約（子はCodexのみ、返せるのはテストと既存.pyの置換、合成題材のみ、Python標準ライブラリのみ、CLIの手動実行）は仕様 `docs/current/specs/2026-09-09-isolated-verification/00-overview.md` のとおりで、広げるにはIssue-0152〜0156の対応（独立試験1回が約1時間40分かかる件を含む）が先に要る。

ユーザーの個別承認: AIが提示した3案（試作で止める／保留を続ける／広げる）に対し、利用者は「1で」と回答した（2026-09-20）。同じ内容への個別回答のため、確定の確認を重ねずAcceptedとする。

## Considered Alternatives

1. **試作で止める**（採用）: 追加投資をやめ、成果は記録として残す。再開が必要になった場合は既存の実装・仕様から始められる。
2. **方針の決定を引き続き保留する**: AI組織の再検討まで決めない。案1との実質的な違いは後片付けへ進むかどうかだけで、保留の間は試作の残存物（全体保存のOAuthを含む）が残り続ける。
3. **広げる（レビュー用または開発用）**: ADR-0205と向きが逆で、要求が決まる前に推測で作ることになる。

## Decision

隔離検証は試作で止める。適用範囲の拡大とIssue-0152〜0156の対応は行わない。

実装（`scripts/verification/`）・仕様・ADR・実験記録はmasterに残す。再開は、ADR-0205の再検討条件に当たり、利用者が判断し指示した時点とする。Issue-0152〜0156は保留とし、再開時に扱う。

## Consequences

- 後片付け（Issue-0157: 停止中のVM19台・全体保存のOAuth・VMごとの通信規則27件）へ進む。削除の対象と時期は本決定に含まず、利用者の個別の承認と操作を前提に別に決める。
- 検証担当が隔離範囲内で追加テストを作成・実行できる構成を目指す要求（ADR-0145）は、今回の試作の範囲で実証した状態で止まる。実プロジェクト・通常運用への適用は行わない。
- 残した実装は、sbx・Codex・Claude Codeの版が進むと、再開時に動作確認と追従が要る。止めている間の保守はしない。
- 本決定はVM・認証情報・ファイルの削除、公開の承認を含まない。
