## 開発フロー/ガイドライン課題

各課題は抽出と分類までにとどめる。**対策の設計・採否判断・ADR 化は行わない**（次サイクルでユーザーが対策要と判断した時点で着手）。

- **課題 #1**: 識別子除去後の文法破綻（R1-a 型）を機械検出できない
  - **事象**: 配布物生成で「ADR-0107 による」「ADR-0072/0080 の骨格」「Issue-0098 の一次記録」の 3 箇所が、識別子除去後に「（の骨格を維持）」「　による」型の破綻文として dist へ出力された。`build-dist.ps1` は規約違反 0 件で通過し、CONTRIBUTING の目視 5 項目だけが検出した（Task 7・`9ceffc9` で修正）
  - **原因**: 機械判定（R1-a/R2）は識別子が括弧の内外どちらにあるかを見るが、「除去後に文が成立するか」は見ない。識別子が文の文法要素（主語・修飾語）になっている場合が死角
  - **影響**: 検出が目視工程への依存になる。目視を省略・簡略化すると壊れた配布物が確定する
  - **なぜフロー課題か**: 配布規約とその検査器（strip-provenance / build-dist）というガイドライン基盤の検出力の問題であり、特定の対象システムに依らない
  - **振り分け判定**: 構造観察型（検査器の設計欠落。delta として表現できない）
  - **関連**: CONTRIBUTING「執行点」・「機械判定が届かない領域」、scripts/lib/strip-provenance.ps1、Issue-0070（スクリプト散文への不達。隣接するが対象領域が異なる）
  - **起票**: Issue-0104（`../../working/issues/flow/0104-provenance-strip-grammar-breakage-not-machine-detected.md`）

- **課題 #2**: SKILL.md のサイズ・分割規範が無い
  - **事象**: 本サイクルで start-work 24.4→34.9KB（+43%）・session-handoff 24.0→30.6KB（+27%）・pre-finalization-review 7.5→13.8KB（+84%）。上位 3 スキルが 26KB 超。実装時レビュアー 3 体が独立に観察として報告
  - **原因**: handoff ファイルには 40KB のサイズ実測トリガー（read/finalize）があるが、スキルファイル自身には目安値も分割・移設の規約も無い。規範追加は常に既存スキルへの追記になる
  - **影響**: session-handoff は Post ラッパーで毎マイルストーン読まれるため、肥大がセッションのコンテキスト費用へ反復的に効く。1 節がファイルの半分を占める偏り（start-work の提示規則節）も観察された
  - **なぜフロー課題か**: スキル体系の運用規約（ガイドラインの器）の欠落であり、対象システムに依らない
  - **振り分け判定**: 構造観察型（体系の俯瞰で見える欠落）
  - **関連**: ADR-0087（handoff サイズトリガー）・skills/ 全域・start-work「確定前レビューの提示規則」節
  - **起票**: Issue-0105（`../../working/issues/flow/0105-skill-md-size-growth-no-norm.md`）

- **課題 #3**: 改訂前退避領域の命名規約・掃除規定が無い
  - **事象**: 本サイクルで `~/.ai-dev-review-snapshots/` に 5 世代のスナップショット（計約 250KB）が残置。規約が定めるのは退避先の場所（リポジトリ外の恒久領域）のみで、ディレクトリ・ファイルの命名規約、保持期間・削除時期の定めが無い
  - **原因**: ADR-0107 決定 3 の退避規定はセッション跨ぎの持続性を優先して恒久領域を第一選択としたが、ライフサイクル側の設計を持たない
  - **影響**: 恒久領域が単調増加する。同名 basename（複数ブランチの SKILL.md 等）の衝突リスク
  - **なぜフロー課題か**: pre-finalization-review スキルの運用規約の欠落であり、対象システムに依らない
  - **振り分け判定**: 構造観察型
  - **関連**: ADR-0107 決定 3・pre-finalization-review「反復の実施」節（改訂前退避）
  - **起票**: Issue-0106（`../../working/issues/flow/0106-review-snapshot-area-no-naming-cleanup-rules.md`）
