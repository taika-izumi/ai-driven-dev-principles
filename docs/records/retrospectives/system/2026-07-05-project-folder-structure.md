  - **対処**: 以後、説明は独立したテキストターンで送り、選択肢はテキスト内に自己完結で列挙する方式へ切り替え。メモリにも記録
- **事象**: AskUserQuestion の誤操作で意図しない選択肢（既存パス維持）が確定し、ADR-0025 旧版の作成→破棄の手戻りが発生

  - **影響**: ADR 作成・インデックス更新・取り消しの往復コスト（未コミットだったため git 履歴への影響なし）
  - **対処**: ユーザーの申告を受けてファイル削除とインデックス復元で即時取り消し
- **事象**: Task 3 のレビューで「パスがバックスラッシュになっている」と誤指摘し、実装エージェントへ不要な差し戻しを1回行った

  - **影響**: 差し戻し往復1回分の時間・トークン
  - **対処**: 実装エージェントの反証を受け、`od -c` によるバイトレベル確認で偽陽性と確定。以後の文字レベル検証はバイトレベルで実施

## 4. Tech Notes（古びない技術知見）

> **スコープ（ADR-0021 / ADR-0012）**
> - **含める**: ツール挙動・環境の罠・回避策・推奨手順など、開発フローやプロジェクトに依存せず古びない汎用技術知見
> - **除外**: 開発対象システムの仕様・ドメイン知識

- **タイトル**: Claude Code の AskUserQuestion は同一ターンの先行テキストを表示しないことがある
  - **コンテキスト**: 説明文を書いてから同一ターン内で AskUserQuestion を呼ぶと、ユーザーには質問ダイアログしか見えないケースがある（2026-07 時点の Claude Code で観測。UI 挙動はバージョンで変わりうる）
  - **知見**: 説明が必要な質問は、説明を独立ターンで完結させるか、選択肢の label/description だけで自己完結させる
  - **参照**: 本サイクルの brainstorming フェーズ（GTD 説明の再質問）
- **タイトル**: git mv によるフォルダ再編は履歴が追跡できる
  - **コンテキスト**: docs 配下の大規模なフォルダ再編（今回92ファイル）
  - **知見**: ディレクトリ単位の `git mv` + `git log --follow` でリネーム履歴を追跡できる。移行先の親ディレクトリは事前に `mkdir` が必要。空になった旧ディレクトリは git が追跡しないため手動削除
  - **参照**: commit afa2df3
- **タイトル**: 検索ツール出力のパス区切り表示は実体と異なる場合がある
  - **コンテキスト**: Windows 環境で grep 系ツールの出力にパスが含まれるとき
  - **知見**: 表示上のパス区切り（バックスラッシュ）を根拠に修正指示を出さない。文字レベルの検証は `od -c` や `sed -n 'Np'` などバイトレベルで行う
  - **参照**: Task 3 レビューの偽陽性
- **タイトル**: Claude Code プラグインのスキルは更新操作まで反映されない
  - **コンテキスト**: プラグイン配信されるスキル（skills/）を編集した後
  - **知見**: インストールはファイルコピーのため、`/plugin marketplace update <name>`（Copilot CLI は `copilot plugin update <name>`）を実行するまで利用環境に反映されない（2026-07 時点の配布機構・コマンド名。機構が変われば要再確認）
  - **参照**: README「インストール」節、本サイクル完了基準8
- **タイトル**: PowerShell の WriteAllLines は Windows で CRLF を書き出す
  - **コンテキスト**: `core.autocrlf=input` の git リポジトリで、スクリプトがファイルを生成するとき
  - **知見**: `[System.IO.File]::WriteAllLines` は環境依存の改行（Windows では CRLF）で書き出すため、LF 正規化された git インデックスと常に食い違い、生成のたびに変更扱いになる。生成スクリプトでは改行コードを明示的に固定する
  - **参照**: 課題 #2（本ファイル Issues）
