## 3. Struggled（苦労したこと・手戻り）

- **事象**: brainstorming 中、選択UIの誤クリックで骨子（判断2）・実装層（判断3）が意図せず確定した状態で進行し、ユーザーの指摘で取り消し・再ヒアリングになった
  - **原因**: 構造化質問ツール（AskUserQuestion）がワンクリックで即「方針確定」として扱われ、確認の一拍がない（Issue-0005 の未対策部分）
  - **影響**: 判断2・3の取り消しと再確認で往復が発生。ただし ADR/実装には未着手の段階で、テキスト運用への切替により実害は限定的
  - **対処**: 該当判断を取り消し、以降の質問はテキストの番号選択肢で提示。誤操作の余地を構造的に排除した

## 4. Tech Notes（古びない技術知見）

- **タイトル**: Bash ツール（POSIX sh）でのマルチライン文字列の渡し方
  - **コンテキスト**: Windows 環境でも Claude Code の Bash ツールは POSIX sh。PowerShell here-string（`@'...'@`）は構文エラーになる
  - **知見**: コミット/マージメッセージなど複数行文字列は `git commit -F <file>` / `git merge --no-ff -F <file>` とファイル経由で渡す
  - **参照**: Issue-0015（起票済み）
- **タイトル**: 選択UIの即確定特性
  - **コンテキスト**: Claude Code の AskUserQuestion はワンクリックで即確定し、取り消し・確認の一拍がない
  - **知見**: 後戻りコストの高い重要判断はテキストの番号選択肢の方が誤操作に強い
  - **参照**: Issue-0005（open）
