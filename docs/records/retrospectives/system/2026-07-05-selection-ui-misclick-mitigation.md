## 4. Tech Notes（古びない技術知見）

- **タイトル**: Claude Code の TUI マウス無効化設定
  - **コンテキスト**: 選択UI（AskUserQuestion 等）はワンクリックで回答が即確定し、確認・アンドゥがない（既知の GitHub issue: anthropics/claude-code #71547, #72614）
  - **知見**: 環境変数 `CLAUDE_CODE_DISABLE_MOUSE_CLICKS=1`（クリック・ドラッグのみ無効、スクロールは維持）または `CLAUDE_CODE_DISABLE_MOUSE=1`（マウスイベント全体を無効。両方設定時はこちらが優先）で構造的に防げる。v2.1.195 以降。keybindings.json ではクリック挙動は制御不可（キーボード操作のカスタマイズのみ）。※「優先関係」「keybindings 制御不可」は 2026-07 調査時点（v2.1.201）の仕様であり、上流の改修（確認ステップ・キーボード限定モード等の追加提案が issue に存在）で変わりうる
  - **回避策・代替**: settings.json の `env` または OS の環境変数で設定する
  - **参照**: Claude Code 公式ドキュメント Fullscreen rendering 節（code.claude.com）、ADR-0036
- **タイトル**: settings.json の `env` の反映タイミング
  - **コンテキスト**: Claude Code の settings.json `env` は**セッション起動時**に注入される
  - **知見**: 設定変更は起動中のセッションには反映されない。「設定したのに現セッションの挙動が変わらない／環境変数が見えない」のは正常で、効果検証は次セッションで行う必要がある。より一般に、起動時注入型の設定（環境変数・プロファイル・デーモン設定など）は「変更したプロセスでは検証できない」パターンとして、検証計画を再起動後に置くこと
  - **参照**: 本サイクルの適用作業（`~/.claude/settings.json`）
