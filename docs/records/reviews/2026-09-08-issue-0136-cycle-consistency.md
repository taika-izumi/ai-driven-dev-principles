# Issue-0136 サイクル全体の整合検査

2026-09-08、主担当が実体を確認。対象はmaster分岐後の共通改定と未コミットの限定接続試験・記録更新。独立レビューとは別に、ADR-0141・0142の確定前に実施した。

## 固定5観点

| 観点 | 確認結果 |
|---|---|
| 1 仕様のスナップショット性 | 現用仕様 `docs/current/specs/2026-08-05-dispatch-and-pre-review-skills-design.md` を全文確認し、実行検査の起動前・受取確認、本文照合、名指し後片付けを追従させた。旧来の「判定誤りは塞がない」は本文照合の導入に合わせ修正。Issue内の承認時点の設計は承認記録を保存し、現在状態と実証欄だけ追従 |
| 2 規範の書き戻し | SKILL本体と条件付き参照の保護条件をADR-0141と照合。既存Codex併用の検証選択はADR-0142。固定MCP補助は実証専用でプラグインへ配布せず、常設基盤の新設や全利用者への依存追加にしていない |
| 3 数値・完了基準 | 常時4件・条件7行を維持。基線4ケースのうち1件不合格→改定後4件合格。改善実証は1件だけ。Pesterは正常1成功・変異1失敗・復元1成功。拒否実測4件、保護6件と以前の試験ファイル3件のハッシュ保全を区別。Claude公開ツール2件。失敗した起動・環境不一致は成功に加算しない |
| 4 経路の閉じ | 下表で到達経路と記録順序を確認。起動前の準備と受取確認を別の時点に置き、条件の重なりで同じ準備を2回要求しない |
| 5 引用の整合 | 下表で旧規範と各ADRの実測・選択理由を照合。Windows1環境・ツール版・固定検査への限定を保ち、全環境対応や無効化設定の成立を主張しない |

## 到達経路と確認時点

| 経路 | 発火・記録 |
|---|---|
| 書き込み操作のない静的検査 | 常時4件と検査行。実行準備は不要。受取後に指摘の前提を確認 |
| コマンド・編集を使える検査、変異指示なし | 手順3で参照を読み全変更経路を確認→起動→手順5で実出力と保全を確認 |
| 検査の中に変異指示あり | 手順2で本文と判定を照合し破壊的検証もyes。手順3の準備は共用、前後比較と受取確認を実施 |
| 検査以外の名目で破壊的検証を委譲 | 破壊的検証yesにより同じ参照・前後比較・受取確認へ到達 |
| 制限を確認できない、または不能 | 書き込み操作のない静的確認へ限定し未検証を明示。限定不能なら起動せず相談 |
| 静的確認から追加実験へ拡大 | 追加の実行前に委譲元へ戻り、対象・範囲・経路を確認。自動解除・再試行をしない |
| 並列かつ変更を伴う検査 | 既存の委譲別コピーと絶対パスを維持し、実行準備は共用。通常の実装委譲へ検査固有の負担を拡大しない |
| 後片付け | 常時2で作成パスと既存物を区別。試験補助では呼び出しごとに新規フォルダ、接続側作成物も記録。削除可能な作成物だけを名指し、既存物の承認は別 |

## 引用・引き写しと選択理由

| 参照・主張 | 判定 |
|---|---|
| ADR-0093のコピー・絶対パス・前後比較・委譲元確認 | 補助として維持。範囲外の破損を事後比較だけで防ぐとはしない。実行検査への拡張は部分修正注記を追加 |
| ADR-0073のミューテーション適用例 | テスト文化に合わせる条件を維持。Pesterを全プロジェクトへ強制しない |
| ADR-0133の判断の分担 | 局所文言・無害な試験・既存引数の具体化だけ自律。既存Codex併用の方式はユーザーの追加回答を記録 |
| ADR-0141 Contextと採用案 | 禁止文だけでの事故・基線失敗に対して全経路の確認を採用。両ツールの限定実証を追記し、未実証だった初期状態と区別 |
| ADR-0141のCodex全環境必須案 | 固定接続の成功後も不採用。Claude単独環境に新依存を課す負担という理由は変わらない |
| ADR-0141の注意書きのみの案 | OS拒否・直接操作除外を確認した今回の採用案と区別し、単なる禁止文の成功として説明しない |
| ADR-0142の既存Codex案・WSL案・保留案 | 既存依存で試せる利点、WSL導入・認証・互換性の負担、保留時の未完を比較したユーザー選択。全体の採用を検証結果から逆算して広げていない |

結果: 仕様の追従漏れを修正。新しい設計条件の追加はなし。ADR-0141は保護条件とツール別確認、ADR-0142は優先する実証方式という各1つの問いに収まり、分割不要。再利用知識は隔離調査第8・9節へ集約し、Issue内の設計・経緯・移譲原本は時点資料として残す。両ツールの少なくとも1経路を確認する完了条件を、今回明示した限定構成で満たす。
