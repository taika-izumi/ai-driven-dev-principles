# 過去ADRから引き継ぐ価値があるレビューの問い

2026-09-12。ユーザーの依頼に基づき、ADR索引と本文を検索し、レビューの有用性・失敗事例・検査対象・後続の部分修正を確認した。全ADRの妥当性を監査したものではない。ADR-0185のプロジェクト全体の目的・方針との整合に加え、以下を今回の見直しへ引き継ぐ候補として推奨する。採用・新規範・追加担当の決定ではない。

## 引き継ぎ候補と理由

| 候補となる問い | ADRの根拠と有用性 | 今回の配置候補・限界 |
|---|---|---|
| **書かれていない必要事項はないか** | ADR-0067・0080。記載済みの内容だけを検証すると選定漏れが下流へ残る。0080は選定漏れ・文書間相互作用・検出力欠陥の3類型を適用例として採用 | 要求担当が全体目的と照合し、敵対的担当が「何が無くても今の検査を通るか」を確認。あらゆる潜在要件の無制限追加を要求しない。0080で見送ったspec→planの専用レビュー枝を自動復活させない |
| **個別には正しくても、組合せで破綻しないか** | ADR-0092。2サイクルで、タスク単位レビュー後に全体を読む検査が7件を検出。二重発火・迂回経路・記録順序、仕様と実体の累積ずれ等 | 成立性と敵対的。編集ファイルだけでなく関連する経路を確認。既存のサイクル全体整合検査を4担当全員へ重複して課す意味ではない |
| **検証そのものは、想定した欠陥を区別できるか** | ADR-0080は検証手段が存在していても検出力が欠けた事例を記録。ADR-0034は計画の編集内容とgrep期待値の矛盾。ADR-0067は計画中のテストコード10件がすべて実行不能だった事例 | 成立性が期待値・実行可能性・検出力を区別し、根拠担当が期待値の根拠を確認。静的な文書確認を実行成功へ読み替えない。写経や変異試験を無条件で全案件へ増設しない |
| **引用・要約で、条件や主張の意味を変えていないか** | ADR-0099。見送り理由が同じADRの実測と正反対だった事例を独立担当2観点が検出。条件付き規範を無条件にした箇所も自己点検を通過していた | 根拠担当を中心に、要求担当が適用範囲を照合。「出典がある」だけで正当化しない。既存の引用整合・過剰適合点検との責務重複に注意 |
| **実証された現象は、本当に対策が必要な問題か** | ADR-0117。既に公開されていた合格基準を秘密として保護する機構を追加した事例。前提確認で不要・重複・欠落・前提誤りを検出 | 根拠担当で保持。敵対的担当が失敗経路を実証しても、保護対象・方針・必要性を別に確認。削減だけでなく必要な保護の欠落も確認。統計設計等は「実在」だけでは判定できないという境界も保持 |
| **限られた事例を、不当に一般化していないか** | ADR-0079。単一プロジェクトのテスト運用由来の項目が汎用的な拘束規範として進み、ユーザー指摘で修正された | 今回の規範改定では根拠と要求の重点項目。出所・対象システム・モデル世代・適用条件を見る。一般の変更へ同じ定型点検を一律に課す判断とは分ける |
| **必要な対策でも、選んだ案の負担は妥当か** | ADR-0125。前提の実在だけでは導入・運用・保守・副作用の費用を比較できない。ADR-0165では既存規定が届いても費用比較なしに27指摘が採用されたとの申し送りを扱う | 根拠・設計判断担当が問題を提起し、既存の主担当による採否手順で比較する。各担当へ同じ採否表を作らせない。実害の初発を「過去の発生なし」で除外せず、必要な保護を費用だけで捨てない |
| **効果を確かめ、不要になれば見直せるか** | ADR-0101・0102。監査では評価できず保留となった44行と、廃止条項のない95行が増殖の背景として記録された。未検出は不要・機会不足・検出器の不備を区別する必要がある | 今回のレビュー規範そのものを評価する設計事項として保持。全レビュー対象へ常設監視を要求しない。「指摘ゼロだから不要」「新工程だから不採用」と即断しない |
| **文脈のない読み手が、正しく解釈して使えるか** | ADR-0091。構造・番号等の整合が確認されても、未定義略号・所在の省略・条件付き義務の表記揺れ・先の手順への参照等が5点残った | 規範・手順の成立性・利用可能性として保持。必要な参照をたどれるかを確認し、自己完結のために定義を全箇所へ複写しない |

## 観点と混同しない運用上の教訓

「未確認と不在を区別する」「反対材料なしの探索先を示す」（ADR-0117）、「原文対比と実行証拠の限界を分ける」（ADR-0186）は、上の全担当に共通する報告の規律であり、追加の専任担当を要する別観点ではない。

ADR-0092の7件は全体を読む自己検査で検出された記録で、4体分離の優位性を実証したものではない。ADR-0099の意味の反転は独立レビューによる検出だが、導入した自己検査で同型を検出できるかは当時未実証と記録されている。失敗の記録・新設理由・対策導入後の効果を混同しない。

ADR-0101は、ADR-0099の「新しい工程・観点・規則を作らない」という当該サイクルの制約を全拡張へ一般化する案を不採用としている。したがって流用対象は引用の意味を照合する問いであり、古い局所的な増設禁止ではない。

## 今回の見直しへの意見

全体目的との整合に加え、**未記載の欠落、組合せの破綻、検証の検出力、引用の意味保存、対策理由の実在**は、4担当の依頼文から読み取れる具体的な問いとして残す価値が高い。過剰一般化・長期負担・効果評価は、今回のように複数プロジェクトへ適用する規範を改定するときに特に重要である。文書の利用可能性は成果物の種類に応じて確認する。

これらをそれぞれ第5〜第13の専任担当へ増やす案ではない。担当ごとの重点と成果物別の確認事項に組み込み、既存の採否・サイクル整合検査・過剰適合点検の実施義務は別に維持する。保持する問いと、歴史上の担当数・発動条件・手順の配置を分けて設計する。
