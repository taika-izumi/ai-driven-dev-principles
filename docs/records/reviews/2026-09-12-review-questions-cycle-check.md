# レビュー観点再編の全体整合確認

2026-09-12。ADR-0189の実装前昇格に対する後追い確認。対象は基点2875fbcからの作業ブランチの変更と未コミット分。仕様・規範の変更があるため、固定5観点で主担当が確認した。モデルによる実装レビューとは別の検査である。

| 観点 | 確認と結果 |
|---|---|
| 仕様のスナップショット性 | 主要仕様の入力・3領域と反証・分担・品質項目・5判定・評価起点を現行ソースと照合。start-work側のdescription操作列挙も復元した。実行手順の一方向依存と、共通の入力定義への参照を混同しないよう主要仕様の説明を補足 |
| 規範の書き戻し | 更新した7スキル文書はADR-0189のDecision 1〜6に対応。既存の常時制約・条件発火・実行保護・採否・反復の条件を保持し、別の常設台帳や評価器は追加していない |
| 数値・完了基準の整合 | 3領域＋反例探索、必要性5判定、6適用例、主要な品質8行。4体は候補で固定義務にしない。15題の入力と期待値はQ01〜Q15で一致。旧定義1実行、新定義1実行、実装レビュー1実行を区別。新定義の評価3件は実装前の設計レビューと混ぜない |
| 経路の閉じ | 下表の入口ごとに、入力の到達先・人数と独立性・結果の照合先・記録時点を確認。共通定義への参照を、レビューの再起動と誤読しない |
| 引用の整合 | 全体目的と承認済み限定、旧5判定、実在だけで決めない専門的検査、過去の人数・世代・検出結果の条件を保持。旧評価の起点を延期せず、未確認を不要へ換算しない。旧規範名と現行の対応は1箇所で明示し、過去記録の名前・数を改変しない |

## 到達経路と記録

| 入口 | 確認範囲・入力 | 結果と記録 |
|---|---|---|
| start-workのspec/plan確定点 | pre-finalization-reviewの提示規則へ。毎回提示とユーザーの実施判断を維持 | 方式が決まってから既存のreview記録へ反映 |
| pre-finalization-reviewの実施操作 | review-procedure→review-criteriaとsubagent-dispatch。全体目的・版・品質項目・分担を渡す | 各担当の独立判断を回収し、主担当が手順5で重複と採否を照合 |
| 他のスキルからの独立レビュー委譲 | subagent-dispatchから同じ入力定義を参照。参照だけで新たなレビューは起動しない | 呼出し側の対象範囲で報告し、全体目的と未確認を共有 |
| フル実施 | 全対象を3領域と反例探索で確認。人数と問いを別に選ぶ | 兼務範囲を明示。兼務を独立反証とは記録しない |
| 差分再確認 | 改訂箇所・対応表と影響する上流条件。既存の新規／継続担当条件を維持 | 改訂前退避・採否・反復提示の順序を維持 |
| 計画逸脱判断の不在の実証 | plan-deviation-defaultsから根拠・設計判断領域の不在の実証へ参照 | 逸脱の型・採用基準・記録形式は変更しない |
| 定義の評価 | 旧定義は旧起点、新定義は実装後の対象レビュー。版と既存観測を保持 | 同じ対象・版の確認を二重計数せず、機会・記録不足は未評価 |

## 引用の対応

- ADR-0185→全担当への全体目的の原文と承認済み限定: 保持。局所要求だけに狭めず、無断で範囲も広げない。
- ADR-0117→5判定・対象例・6適用例・専門的検査の境界: 保持。必要性の不明を「前提誤りだが必要」へ換算しない。
- ADR-0125/0165→増設費用比較: 主担当の既存採否へ配置。全担当へ同じ審査を重ねない。
- ADR-0186→原文・版・未確認の入力契約: 実装レビューR2で明文を復元。descriptionの2操作も既存仕様へ復元。
- ADR-0189→担当境界、人数と独立性、評価起点: ソース・仕様・配布へ対応。4体の便益は未実証として保持。
- 過去の人数別コスト・検出数: 原条件・世代・限定を維持。今回の15題や新構成の実績として加算しない。

今回の修正は参照・既存契約の復元と、実行上の依存の説明の精度を上げるもの。新しい設計上の問いは追加していない。結果は「実施（修正: 本記録）」としてhandoffへ残す。
