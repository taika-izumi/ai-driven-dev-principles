# Issue-0005: 選択UIの誤操作が即「方針確定」として扱われる

- **Status**: open
- **Opened**: 2026-07-05
- **起票元**: retrospectives/flow/2026-07-05-project-folder-structure.md 課題#2
- **関連**: ADR-0006、ADR-0024

## 課題内容

選択UIの誤クリックが確認ステップなしに意思決定として確定し、意思決定の継続検出ルール（ADR-0006）により即座に ADR 作業へ増幅される（要約。詳細は起票元参照）。

## 検討状況

- 2026-07-05: Issue-0012 対策サイクル（ADR-0035）の brainstorming 中に本課題の実例が発生。AskUserQuestion の選択UIで骨子・実装層の判断が誤クリックにより意図せず確定し、取り消し・再ヒアリングになった。ユーザー指摘後はテキストの番号選択肢運用へ切り替えて再発を防いだ。対策方針の方向性として「後戻りコストの高い重要な判断では選択UIをやめ、選択肢＋推奨をテキスト提示する（ADR-0024 の改定を伴う）」がユーザーと合意されており、次サイクルで扱う（起票元: retrospectives/system/2026-07-05-question-tool-timeout-autonomy.md）
