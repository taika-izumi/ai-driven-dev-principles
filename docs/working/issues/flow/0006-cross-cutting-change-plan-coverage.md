# Issue-0006: 横断的なパス変更で実装計画に網羅漏れが出る

- **Status**: open
- **Opened**: 2026-07-05
- **起票元**: retrospectives/flow/2026-07-05-project-folder-structure.md 課題#3

## 課題内容

横断的な変更（パス変更等）の際、計画時の変更対象リストが仕様書で明示したファイルに偏り、リポジトリ全体の旧参照の洗い出しがタスク末尾の検証に寄って網羅漏れが出る（要約。詳細は起票元参照）。writing-plans 時の横断洗い出し手順の問題。

## 検討状況

- 2026-08-07: ADR-0080 のサイクルで本課題を対策候補として検討し、対象外と確定した。本課題の漏れは「仕様書に明示されていない旧参照の洗い出し」の側であり、spec 要件を母数とする spec→plan 突合では原理的に検出できない（ADR-0080 Considered Alternatives 6）。有効な対策は横断洗い出し自体を plan 作成手順へ組み込む方向であり、確定前レビューの提示規則とは別の設計になる
