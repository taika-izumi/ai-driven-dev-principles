## 課題内容

Claude Code のプロジェクトメモリが、ガイドライン規範の欠落を静かに補完しうる。メモリはツール固有・プロジェクト固有・プラグイン配布の外側にあり、体系から観測も配布もできないため、補完が効いているプロジェクトでは体系側の欠落が見えなくなり、信頼性評価を誤らせる。新規プロジェクト・他ツール環境では補完が効かず、同じ欠落が再現する。

実例: LoopForAlpha のメモリ `feedback-follow-mandatory-steps` が Post ラッパーの消し込み規律を補完しており、本 repo との消化率差の主因だった（Issue-0037 の起票時誤診の遠因）。個別事例としては ADR-0057 で規範を明文化して解消したが、「メモリが補完している他の規範」が存在しないかは未走査。

詳細（事象/原因/影響）は起票元の振り返りファイルが正。
