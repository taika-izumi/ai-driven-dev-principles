## 課題内容

節目で残作業の規模を再見積もりし、サイクル分割の要否を利用者に確認する工程がフローに存在しない。計画確定後に判明した事項でスコープが伸びても、気づく仕組みがない。

本サイクルの実例: 計画は Task 1〜8 で確定したが、実行中に Task 7 のスコープ変更（ADR-0065）、ADR 粒度点検による 2 本の分割新設（ADR-0068 / 0069）、母数の訂正が追加され、ADR は 1 サイクルで 9 本（ADR-0061〜0069）になった。

**ADR-0062 の Consequences に「規模膨張の歯止めが無い」と自ら記録したうえで着手し、予告どおりの膨張が起きた。** 予測できていても止める手段が無いことが確認された。
