# Issue-0054: pre-action-review の撤退規範が一時的なインフラ障害と恒常的な失敗を区別しない

- **Status**: open
- **Opened**: 2026-08-06
- **起票元**: `retrospectives/flow/2026-08-06-intake-structural-flow-issues.md` 課題#1
- **関連**: `pre-action-review` スキル（フォールバック節「同じエラーが3回以上繰り返される → 撤退」）、worklog `MakeAiInstructions-2026-08-06-01`（該当事象の delta 記録）

## 課題内容

`pre-action-review` のフォールバック規範は「同じエラーが 3 回以上繰り返される → 撤退」と定めるが、エラーの種別（恒常的な失敗か、復旧見込みのある一時障害か）を判定基準に含めていない。

実測（2026-08-06）: ツール権限分類器の一時障害で同一エラーが 12 回超繰り返されたが、エラー文面が「wait briefly and retry」と復旧見込みを明示していたため、エージェントは撤退せず段階待機→再試行で作業を完遂した。判断は結果的に妥当だったが、規範に形式上反する現場判断であり、記録されなければ規範の拘束力が下がる。

詳細（事象/原因/影響)は起票元の振り返りファイルが正。

## 検討状況

- 2026-08-06: 起票。対処の方向（未決）: (a) 撤退規範に「エラー自体が一時性と再試行を明示する場合は、クリーンな区切りを維持したうえで待機→再試行してよい」等の例外条件を追加 (b) 待機再試行の上限（回数・時間）を定める (c) 規範から外れた現場判断をした場合の記録義務を定める
