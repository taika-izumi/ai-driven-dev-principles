# Issue-0079: 「正本が handoff 以外にないもの」の保護規則に、正本を外部へ移す誘導と上限がない

- **Status**: open
- **Opened**: 2026-08-13
- **起票元**: feature/handoff-bloat-analysis サイクルのアドホック調査（LoopForAlpha のハンドオフ肥大化）
- **関連**: ADR-0075（基準付き圧縮の「圧縮しないもの」規定）、Issue-0049（closed。肥大化の元課題＝ADR-0074/0075 の起点。本課題はその対策の抜け道を扱う）、`skills/session-handoff/SKILL.md`、Issue-0021（Tech Notes の横断再利用＝知見の受け皿候補）、Issue-0078 / Issue-0080 / Issue-0081（兄弟課題）

## 課題内容

finalize の基準付き圧縮（ADR-0075）は「正本が handoff 以外にないもの（進行中タスクの状態・残り、現役の申し送り・懸念）」を圧縮対象から除外する。この規則は正しく動くが、**handoff を正本として書けば何でも無制限に保護される**という抜け道を持ち、正本を issues / plan / 知見置き場へ移すことを促す規範も、保護量の上限もない。

LoopForAlpha での実測（2026-08-13、`docs/working/handoff/master.md` 99KB のうち）:

- 「進行中のタスク」節が 31.5KB。レビュー・ミューテーション検査で得た教訓の番号付きリストが 32 項目、フェーズ跨ぎの申し送り小節が 5 つ蓄積
- 「正本がここにしか無いもの」と明示した小節まで存在する（handoff を意図的に正本として使っている）
- 蓄積されている情報自体は高価値（テスト設計の穴・検査の落とし穴など引継ぎ精度に直結する内容）で、**削るべき情報ではなく、置き場を誤った情報が溜まっている**

## 影響

- 圧縮が設計どおり動いても肥大が止まらない（保護対象がそのまま成長する）
- 教訓・申し送りが handoff 内に埋まるため、サイクルを跨いだ再利用（Issue-0021 の問題意識）もできない

## 対策の方向（採否は未定）

- 申し送り・教訓の正本は issues / plan の当該節 / 知見置き場（Tech Notes 等）に置き、handoff には参照＋1 行要約のみを書く規範を追加する
- finalize に「handoff が正本になっている記述の移設」を工程として組み込む（圧縮の前段で正本を外へ作り、参照へ置換する）
- 保護対象の分量に目安（上限）を設け、超過時は移設を促す
