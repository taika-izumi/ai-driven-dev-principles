# Issue-0086: 決定の見送り理由が、引用した実測と矛盾していないかを突合する工程がない

- **Status**: open
- **Opened**: 2026-08-15
- **起票元**: `retrospectives/flow/2026-08-15-issue-0076-dispatch-isolation.md` 課題#1
- **関連**: ADR-0079（過剰適合点検）、ADR-0092（サイクル全体整合検査の観点 5）、ADR-0093（本事象の発生元）、ADR-0059/0060（粒度点検）

## 課題内容

ADR-0093 初稿で、代替案の見送り理由を「委譲先の報告を読めば委譲側も同じ検出ができる」とした。しかし同じ ADR の Context が引用する実測は、委譲先 2 体がともに複製での実施を報告した上で破壊が起き、実際に検出したのは委譲側自身の状態確認だった、というものである。見送り理由は引用元の実測と正反対だった（2026-08-15 実測。独立レビュー 2 観点が検出）。

既存の検査工程のどれもこの軸を見ていない:

| 工程 | 見ているもの | この型を見るか |
|---|---|---|
| 過剰適合点検（ADR-0079） | 出所の偏り・システム/モデル依存性・退役経路 | 見ない |
| 粒度点検（ADR-0059/0060） | タイトルと本文の決定の対応 | 見ない |
| サイクル全体整合検査 観点 5（ADR-0092） | 引用元のゲート（適用条件）の脱落 | 見ない（ゲートの有無であって主張の向きではない） |

## 影響

- 独立レビューを実施しなければ、実測に反する根拠で決定が確定していた
- 確定前レビュー（`pre-finalization-review`）の発動はユーザー指示のみであり、毎回実施される工程ではない。レビューを見送るサイクルではこの型が素通りする
- 決定そのものは妥当でも見送り理由が誤っていると、後のサイクルで同じ代替案を再検討する際の判断材料が汚染される

## 対策の方向（採否は未定）

- サイクル全体整合検査（ADR-0092）の観点 5 を「引用の条件保存」から「引用の条件保存と主張の向きの一致」へ拡張する
- あるいは `decision-log` の ADR 作成手順へ「Context の実測と Considered Alternatives の各評価の向きを突合する」ステップを置く
- あるいは過剰適合点検の観点として追加する（ただし同点検は規範の一般性を見る工程であり、責務がずれる可能性がある）
