# Issue-0089: 指定席（議事録・インシデント報告等）のファイル命名・索引の規約が未定義

- **Status**: open
- **Opened**: 2026-08-15
- **起票元**: Issue-0088 対策サイクルの設計議論（ADR-0095 の Consequences）
- **関連**: ADR-0095（指定席優先の境界規則）、`docs/overview/folder-structure.md` §5・§6（配置定義のみ存在）

## 課題内容

`docs/records/minutes/`（議事録）や `docs/records/`（インシデント報告）などの「指定席」は、配置先の定義しか持たず、ファイル命名・索引・内部体系の規約が無い。ADR-0095 が Issue フォルダから指定席への送付を無条件優先にしたため、指定席側が無秩序だと追跡性がそこで劣化する（Issue 側からは索引の外部参照 1 行で辿れるが、指定席を直接ブラウズする経路が規約を持たない）。

議事録は複数 Issue・複数トピックにまたがることが多く、Issue 側の体系（番号接頭辞）をそのまま流用できない可能性がある。

## 対策の方向（採否は未定）

- 指定席ごとに命名（日付＋主題）と索引 README の規約を定義する（`docs/reference/` の索引 README 方式の横展開が候補）
- Issue-0088 の成長様式の観点（件数増加型）も併せて検討する
