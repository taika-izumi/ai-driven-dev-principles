# Issue-0095: 計画の検証期待値突合（A-13）は検出力が反証されており再設計が必要

- **Status**: open
- **Opened**: 2026-08-16
- **起票元**: Issue-0092 監査の検出力実証（ADR-0101 決定 2）
- **関連**: ADR-0101、`docs/records/audits/2026-08-16-guideline-process-audit/report.md` 1-5・3-3、Issue-0056（検証コマンドの実行可能性）、Issue-0073（期待値の陳腐化）

## 課題内容

CLAUDE.md「検証」の「実装計画を作成したら、各検証ステップの期待値がタスクの編集内容と矛盾しないかを突合すること」（監査台帳 A-13）は、対象 141 行で唯一「検出できなかったこと」が実測された規範である。捕捉できなかった実測 2 件（worklog `MakeAiInstructions-2026-08-07-02` / `-05`。いずれも「計画の実行可能性検査では通り、実行時に初めて判明」）があり、Issue-0056・0073 も open のまま。保留 44 行が「観測不足」であるのに対し、本行は「観測した結果、機能していないことが分かっている」行であり、削減ではなく作り直しの対象。

## 対策の方向（採否は未定）

Issue-0056（確定前に検証コマンドを実際に実行する）・Issue-0073（実装中の期待値更新規約）と同時に扱い、机上突合を「実行による確認」へ置き換えるか補強する設計を検討する。本監査サイクルでも同型の事象が再発している（計画の期待値 ≥101 が実測 99 と食い違い・H 群分母の偽ヒット等）。
