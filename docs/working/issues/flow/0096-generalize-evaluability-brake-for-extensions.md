# Issue-0096: 増設の歯止め（評価可能性の義務化・弱い形）の CONTRIBUTING への一般規範化が未実施

- **Status**: open
- **Opened**: 2026-08-16
- **起票元**: Issue-0092 監査のユーザー判断（ADR-0101 決定 3）
- **関連**: ADR-0101（決定 3 が規範の内容を確定済み）、ADR-0099（強い形の先例）、ADR-0079（過剰適合点検。本規範化はその適用対象）

## 課題内容

ADR-0101 決定 3 で確定した「評価可能性の義務化（弱い形）」がまだ規範文書に存在しない。内容は次の 2 点を CONTRIBUTING（拡張の入口）へ 1〜2 文で明文化すること:

- (a) 規範・工程を新設する ADR は、「既存工程の文言拡張・リスク受容で足りないか」の比較を Considered Alternatives に含める
- (b) 新設する場合は、期待検出量（発火機会の見込みと捕捉したい欠陥型）と観測可能な退役条件を ADR に 1〜2 行で明記する

強い形（新設を既定で禁止）は ADR-0101 Considered Alternatives 1 で不採用が確定している（新工程 H-02 が 8 回の発火で 156 件を検出した実測が反対材料）。

## 対策の方向（採否は未定）

CONTRIBUTING の「全シナリオ共通」節（過剰適合点検の近傍）へ配置し、decision-log の ADR 作成手順との重複が生じないか（境界原則 ADR-0098: 複写禁止）を確認して実装する。規範の追加にあたるため、過剰適合点検・執行点 4 手順・plugin version bump の対象。

## 検討状況

- 2026-08-16: 起票。規範の内容自体は ADR-0101 決定 3 で確定済みで、残るのは配置と文言の実装のみ（小規模）。
