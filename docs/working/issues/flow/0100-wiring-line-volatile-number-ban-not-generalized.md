# Issue-0100: 配線行に統合先の可変数値を書かない規律の恒久規範化が未実施

- **Status**: open
- **Opened**: 2026-08-17
- **起票元**: retrospectives/flow/2026-08-17-issue-0093-0094-integration.md 課題#1
- **関連**: ADR-0105（配線行の規律。本サイクル限りの作業方式として定義）、CONTRIBUTING「全シナリオ共通: 配布対象ソースの記法規約」（恒久規範化の候補位置）

## 課題内容

ADR-0105 は統合サイクルの作業方式として「配線行に統合先の改定で変わりうる数値（件数・閾値・手順数）を書かない」規律を定めたが、適用範囲は本サイクル限りで、恒久規範ではない。同サイクルの執行点総ざらいで既存の件数参照ドリフト 1 件（extend-guidelines の「目視が要る 3 点」が CONTRIBUTING の 5 項目定義に不追従）を実測し、件数除去で修正した実績がある（コミット `a04fb5a`）。恒久規範が無いままでは、将来の編集で同型ドリフトが再発しうる。詳細は起票元の振り返りファイルが正。

## 対策の方向（採否は未定）

CONTRIBUTING の記法規約または参照行の書き方に関する共通規範へ、一般則として吸収する（規範化する場合は extend-guidelines 経由で新設の評価可能性の記載要件を満たすこと）。
