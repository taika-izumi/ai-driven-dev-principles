## 課題内容

AGENTS.mdは、質問時に番号付き選択肢・先頭の推奨・理由を求める。しかし本セッションのCodexは番号付き選択肢を提示せず、調査報告後や前提への質問後に次手へ進まなかった。質問形式と作業継続は別の症状として扱う。

ユーザーはrun1の分析から、Defaultモードで通常メッセージの選択肢付き質問を制限する開発者指示が注入されると報告した。CLI 0.153.4では `include_collaboration_mode_instructions=false` によってモード指示ブロックが生成入力から除外されることをAIが確認した。ユーザーはCLIで意図した挙動となったこと、共通設定後のアプリrun5で選択肢が表示されたことを報告した。
