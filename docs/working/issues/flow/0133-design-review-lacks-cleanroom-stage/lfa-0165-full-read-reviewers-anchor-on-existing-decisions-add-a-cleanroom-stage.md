## 課題内容

第 3 巡（観点 M = 評価の方法論 / C = 構築のやり方）は、レビュアー 3 体がいずれも ADR 27〜54 本と仕様を全文で読んでから所見を出した。典拠の正確さは担保されたが、利用者が別の AI 2 体へ設計要約だけを渡して得た意見のうち「シグナルの質を資金制約・曝露から切り離して測る（Signal Quality テスト）」「Event 型 / Ranking 型の分離」「タイミング保存の銘柄シャッフル帰無」はレビューから出ていなかった。主因は (1) ブリーフの観点が「線の引き方（合否の線が主張どおりか）」に閉じ、「評価対象の妥当性（測っている量は問いに答える量か）」を独立の観点として置かなかったこと (2) 全文読みが既存決定（ADR-0117 / 0159 / 0176・転写幅実験の結論）への係留を生んだこと、と判定した（確率的な取りこぼしは副次的）。外部 AI は現状認識に誤り（固定スロット方式が既に現行であること等）を含む一方、既存決定に係留されず代替案を出せた。

対策の方向（設計レビューの体制への追加。適用は本プロジェクトのレビュー計画で、汎用化は配信元への申し送り候補）: (1) 観点に「評価対象の妥当性 = 第一原理から設計するなら何を測るか」を独立に置く。(2) 全文読みのレビュアーに加え、ADR・仕様を読まないクリーンルームのレビュアー 1 体に最終像 + 誤りのない設計要約（1〜2 ページ）だけを渡して代替設計案を出させ、別の 1 体が現行設計と突合して「採用済み / 既存決定と衝突（ADR 番号）/ 新規」に分類する。(3) 外部意見を受けたときは、まず意見の現状認識（前提）を実体で検査する。
