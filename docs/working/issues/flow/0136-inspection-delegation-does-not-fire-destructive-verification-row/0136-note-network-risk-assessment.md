# 通信リスクを許容して限定利用できるか

問い: ファイルの書き込み制限は成立するがループバック通信が可能な構成を、どの条件なら利用候補にできるか。

## 評価の結論

**通常利用の包括的な許容は勧めない。** 現構成はコピー外の読み取りを禁止しておらず、ローカル通信で実際にデータを往復できる。読み取れる情報の流出や、ローカルサービス経由の状態変更は、原本ファイルへの書き込み拒否だけでは防げない。

12:47〜12:50の限定利用条件の確認で、検証ユーザーが実在するCodex認証情報の標準保存先`auth.json`を読み取り用に開けることを確認した（内容は未読）。また、ChromeDriverなどのローカル待受が存在する。現在のPCと権限構成をそのまま使う場合、提示した限定利用条件は満たせていない。

一方、確認した公開宛先への直接TCP接続は拒否された。通信が全面的に開放されていると結論する材料ではない。信頼できる題材を扱う限定試験は候補だが、以下の条件確認と個別判断が必要。今回の進行承認（ADR-0149）を通信の受容や実エージェント起動の許可へ読み替えない。

## リスクと条件

| リスク | 想定経路 | 評価・対処候補 |
|---|---|---|
| PC内のDBや管理APIの変更 | エージェントや実行したテストがlocalhostの操作用サービスへ接続 | ファイルACLとは別経路。対象サービスの認証・権限・接続可能性を確認するまで許容しない |
| 情報流出 | コピー外から読み取った情報を、ローカルのプロキシ・中継サービスへ渡す | 直接外部接続の拒否だけでは除外できない。読み取り範囲の限定または機密のない別環境が必要 |
| 別ツールによる外部操作 | Web・アプリ・MCP・フック・エージェントの再委譲 | 新exec構成で公開される操作をまだ確認していない。コマンドの通信制限とは別に確認する |
| 誤操作や信頼できないコードの実行 | 生成テストや依存が意図しないコマンドを実行 | 「通信しないよう指示する」だけは保護として数えない。信頼できない入力の通常利用は現構成の候補から外す |

ローカルの実サービスへの接続・操作、秘密ファイルの読み取り、サービス停止は試していない。上表の攻撃経路がこのPCで実際に成立すると断定はしていない。

## 限定試験を選ぶ場合の条件案（未採用）

合成データまたは公開してよい情報だけを使い、読み取り可能範囲に秘密がないこと、接続可能なローカルサービスに状態変更・中継の危険がないこと、Web・アプリ・MCP等を公開しないことを確認する。そのうえで、限定した1件のエージェント試験を個別に判断する。

利用者が毎回DB・プロキシ・管理サービスを停止したり、読める秘密を点検したりする運用には負担と見落としが生じる。これを通常運用の必須作業として採用する決定はしていない。これらを安定して保証できない場合は、機密・本番サービスから分離した環境を比較する方が維持しやすい可能性がある。

## 次の判断材料

通信に依存しないコピー・結果照合・プロセス停止の先行検証結果と合わせ、限定試験の条件を満たせるか、別環境を使うかを判断する。追加のWindows内部原因追跡は現時点では優先しない。ファイル書き込み保護、読み取りの機密性、通信、エージェントの判断品質を別々に評価する。

## 限定利用条件の確認（2026-09-09 12:47〜12:50）

ユーザーが「限定利用の条件を確認する」を「１で」で選択。サービスへの接続・停止・設定変更を行わず、待受メタデータと既知の認証保存先へのOSの読み取り許可を調べた。

### ローカルサービス

TCP待受40行を確認（IPv4・IPv6の重複を含む）。ループバック限定19行、全インターフェース19行、特定インターフェース2行。プロセス名は18種類。ChromeDriver（127.0.0.1と::1の58748）、Chrome（127.0.0.1:58751）、ASUSの各種サービス、OneDrive、Windows標準サービス等が含まれる。

プロセスのコマンドライン、サービスへの要求・応答、認証の有無は確認していない。待受が存在することと、検証ユーザーから無認証で操作できることは区別する。特定IPだけの待受への到達性も未検証。

[ChromeDriverの公式注意事項](https://developer.chrome.com/docs/chromedriver/security-considerations)は、既定ではローカル接続のみを許可し、機密情報へアクセスできない試験用アカウントと保護された環境での利用を勧めている。この一般仕様を、今回のプロセスの認証状態や操作成功の実証として扱わない（2026-09-09閲覧、Googleの一次情報）。

### コピー外の読み取り権限

同じCodex CLI 0.153.4・elevated・inspection・network.enabled=falseのcommand/exec経路で、ReadAccessProbe.ps1を実行。対象ファイルは読み取りハンドルを取得した直後に閉じ、Read・コピー・ハッシュ計算を行っていない。内容や認証値は記録していない。
