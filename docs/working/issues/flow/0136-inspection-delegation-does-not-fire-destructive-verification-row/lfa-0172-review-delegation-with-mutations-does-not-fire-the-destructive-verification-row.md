# Issue-0172: 検査委譲の中で変異実験を指示すると `subagent-dispatch` の B 群「破壊的検証」が発火せず、リポジトリ外の破壊が誰にも検出されない

## 課題内容

**事象**: 第126回の Task 2 で、仕様適合レビューとコード品質レビューをサブエージェントへ委譲した。委譲元は B 群判定行を `検査=yes / ミューテーション=no / 並列書き換え=no / 計画実装=no / 長時間書き込み=no / 破壊的検証=no` と書いたが、**同じプロンプトの本文で変異実験（対象を壊して検査が赤くなるかを測る）を明示的に指示していた**。委譲先の変異台本の書き戻し先が Pester モジュールの `Pester.ps1`（`<OneDrive>/ドキュメント/PowerShell/Modules/Pester/5.7.1/Pester.ps1`・16,695 バイト）へ解決され、同ファイルがゴール定義 0004 の本文（22,371 バイト）で丸ごと上書きされた。以後 `Invoke-Pester` は全コンテナが ParseException で落ち、`Failed: 606` を返すようになった（Discovery は成功するため**退行と読み違えやすい**）。

**委譲先は正しく報告していた**: 当該エージェントは作業前後の突合を行い「実リポジトリは無変更（`git status --short` = 委譲元の編集 1 本のみ）」と報告している。破壊はリポジトリ外で起きたため、`git status` では原理的に検出できなかった。破損の発見は、後続のコード品質レビューが「プロジェクト自身の検証コマンドが走らない」と報告したことによる（発見まで約 40 分）。

**原因（3 層）**:

1. **委譲元の判定漏れ**: B 群の発火条件表は「検査・監査・走査を委譲するとき」と「ミューテーション検査を委譲するとき」「破壊的検証…を委譲するとき」を別行に持つため、**検査委譲の中で変異を指示する形**が「検査」行だけの判定で通ってしまう。表の 3 行が排他的に読める。
2. **展開項目の射程**: B 群「破壊的検証」の展開項目は「**検証対象範囲**のファイル一覧と内容ハッシュを作業前後で記録・比較させる」であり、**書き込み先が想定外の場所へ解決した場合**（＝検証対象範囲の外）を覆わない。同項目の注記は「実リポジトリのルートを絶対パス指定した `git status` は補助にできるが、未追跡ファイルの内容改変・ignore 対象・リポジトリ外の破壊は検出できない」と正しく警告しているが、**その検出手段は用意されていない**。
3. **この環境固有の落とし穴**: Pester の実行フェーズでは `$PSCommandPath` / `$MyInvocation.MyCommand.Path` が**テストファイルではなくモジュールの `Pester.ps1`** を指す。変異台本がこれらを書き込み先の算出に使うと、モジュール本体を書き潰す。

**影響**: 検証ツールが約 40 分使用不能。リポジトリ・コミット済み成果物への影響はゼロ。復旧は PowerShell Gallery の配布物（`Install-Module` が使うのと同じ nupkg）から 1 ファイルのみ差し替えて完了した（無傷 21 ファイルのハッシュ全数一致＋差し替えたファイルの Authenticode 署名 Valid で同一版の本物であることを確定）。

**対策の方向**（採否・設計は配信元。本課題は申し送り単位）:

1. **発火条件の重なりを明示**: 「検査・監査・走査の委譲であっても、委譲プロンプトが**変異・書き換えを伴う実験**を指示するなら、ミューテーション行と破壊的検証行も併せて発火させる」を B 群の表または手順 2 に明記する。現行の「全行を読み下ろして判定行を残す」だけでは、行の意味の重なりを委譲元が見落とす。
2. **展開項目の追加**（破壊的検証行）: (a) 書き込み先は**固定文字列から組んだ絶対パス**とし、書き込みの直前に隔離ルート配下であることを突合させる。(b) `$PSCommandPath` / `$MyInvocation.MyCommand.Path` のような**実行文脈で解決先が変わる変数を書き込み先の算出に使わせない**。(c) 隔離ルート外への書き込みを試みたら停止して報告させる。
3. **検出手段の用意**: リポジトリ外の破壊を事後に検出する軽量な手段（委譲前後で「委譲先が触りうるツールチェーンのファイル一覧＋ハッシュ」を記録する等）の要否を検討する。射程と費用の釣り合いは配信元の判断。

## 現在地の要約

- **事象**: 検査委譲の中で委譲先が変異実験を行うと `subagent-dispatch` の B 群「破壊的検証」が発火せず、リポジトリ外の破壊（第126回 = Pester モジュール本体 `Pester.ps1` の上書き）が `git status` で検出できない。第127回に (a) 委譲元が変異を「範囲外」と禁じた検査委譲でも委譲先が自発的に変異を行い、(b) A 群 2 を明示した委譲でも委譲先がリポジトリ外の既存物を事前承認なく削除した（削除対象の選び方 = 更新時刻・ワイルドカードで絞る型）
