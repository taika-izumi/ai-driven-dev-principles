# 隔離検証の共通起動処理（先行実装）

通信条件が未解決のため、現在使えるのはAIを起動しない部品の検査だけです。通常利用向けの共通CLIは未実装です。モデルへの依頼、原本への自動適用、導入や公開は行いません。

## 検証できる部品

- `RequestCopy.psm1`: 依頼検査、対象一覧・ハッシュ、コピー、独立Gitの初期化。
- `Execution.psm1`と`ProcessHost.ps1`: 明示したプロセスの出力回収・時間超過・Windowsジョブによる子プロセスの停止。ジョブはプロセス管理用であり、ファイルや通信を隔離するものではありません。
- `Result.psm1`: 実行記録・最終応答・成果物・原本状態の照合。

Windows、PowerShell 7、Gitが必要です。検証ではCodexの実行ファイルの実在も確認しますが、下記コマンドからモデルは起動しません。

```powershell
pwsh -NoProfile -File scripts/verification/tests/Run-IndependentTests.ps1
```

試験用データはこのworktreeの`.tmp/verification-tests/`に実行ごとに新規作成します。自動の後片付けは行いません。

## 残る実装と制約

権限プロファイルを実エージェントへ適用する起動処理、共通CLIの結合、Claude Code・Codex双方からの実証は未完了です。依頼元を示す`caller`の文字列だけでは実証になりません。

初回のコピーはGit履歴・インデックス・フックを引き継ぎません。再解析ポイントとサブモジュールのディレクトリ入力は拒否します。`.codex`・`.claude`・`.agents`・`.mcp.json`の起動設定は通常コピーから除外して理由を残します。設定自体を検証するための保護された別入力や、導入設定ファイルの取扱いは、実エージェントの起動・CLI結合時に確認する必要があります。

部品テストの成功は、通信リスクの受容や隔離環境の完成を意味しません。現状の評価と条件はIssue-0136の`0136-note-network-risk-assessment.md`を参照してください。
